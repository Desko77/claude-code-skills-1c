# Глоссарий терминов транскрибации.
#
# Слева - правильное написание, справа через запятую - ослышки распознавателя.
# Строка без "=" - термин только для подсказки распознавателю (hotwords), замен не делает.
# Все после "#" - комментарий.
#
# Правила:
#   - Ослышки пишутся ТОЙ формой, какой они реально вышли из распознавателя (падеж, число).
#     Морфологии здесь нет: угадывать словоформы опаснее, чем пропустить одну.
#     Поэтому и слева форма пишется под стать ослышке ("гашения = базаты", а не "гашение").
#   - Регистр не важен: "ДАКС" ловит и "дакс", и "Дакс". Дублировать формы по регистру не нужно.
#   - Ослышки короче 3 символов игнорируются - на них замена лезет внутрь чужих слов.
#   - Дополняй файл по итогам своих встреч: увидел ослышку в расшифровке - добавь строку.
#     Правильные написания одновременно уходят подсказкой в распознаватель, поэтому со временем
#     часть ослышек перестает появляться вовсе.
#
# Проверить файл и замены: python scripts/glossary.py "текст с ослышкой"
