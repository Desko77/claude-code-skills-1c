# /db-dump-dt - Выгрузка информационной базы в DT-файл

Выгружает всю информационную базу в DT-файл: конфигурация, данные, список пользователей, настройки. Это полный бэкап ИБ и стандартный способ переноса базы (в том числе файловая -> серверная и обратно).

Отличие от `/db-dump-cf`: CF содержит только конфигурацию, DT - всю базу целиком.

## Usage

```
/db-dump-dt [database] [output.dt]
/db-dump-dt dev backup.dt
/db-dump-dt                          - база по умолчанию, файл backup.dt
```

> Выгрузка требует монопольного доступа: активные сеансы должны быть завершены, иначе платформа вернет ошибку. На больших базах выгрузка идет долго и требует места на диске.

## Параметры подключения

Прочитай `.v8-project.json` из корня проекта. Возьми `v8path` (путь к платформе) и разреши базу:
1. Если пользователь указал параметры подключения (путь, сервер) - используй напрямую
2. Если указал базу по имени - ищи по id / alias / name в `.v8-project.json`
3. Если не указал - сопоставь текущую ветку Git с `databases[].branches`
4. Если ветка не совпала - используй `default`
Если `v8path` не задан - автоопределение: `Get-ChildItem "C:\Program Files\1cv8\*\bin\1cv8.exe" | Sort -Desc | Select -First 1`
Если файла нет - предложи `/db-list add`.
Если использованная база не зарегистрирована - после выполнения предложи добавить через `/db-list add`.

## Команда

```powershell
powershell.exe -NoProfile -File skills/1c-db-dump-dt/scripts/db-dump-dt.ps1 <параметры>
```

### Параметры скрипта

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-V8Path <путь>` | нет | Каталог bin платформы (или полный путь к 1cv8.exe) |
| `-InfoBasePath <путь>` | * | Файловая база |
| `-InfoBaseServer <сервер>` | * | Сервер 1С (для серверной базы) |
| `-InfoBaseRef <имя>` | * | Имя базы на сервере |
| `-UserName <имя>` | нет | Имя пользователя |
| `-Password <пароль>` | нет | Пароль |
| `-OutputFile <путь>` | да | Путь к выходному DT-файлу |
| `-StrictLog` | нет | Отказ в журнале поднимает код возврата до 1, даже если платформа вернула 0 |

> `*` - нужен либо `-InfoBasePath`, либо пара `-InfoBaseServer` + `-InfoBaseRef`

Расширения отдельно не выгружаются: DT всегда содержит базу целиком вместе с установленными расширениями.

## Коды возврата

| Код | Описание |
|-----|----------|
| 0 | Успешно |
| 1 | Ошибка (см. лог) |
| 2 | Неверные аргументы (python-версия, argparse) |

## После выполнения

Прочитай лог-файл и покажи результат. Если есть ошибки - покажи содержимое лога. Типовая причина ошибки - активные сеансы в базе (нужен монопольный доступ).

## Примеры

```powershell
# Полный бэкап файловой базы
powershell.exe -NoProfile -File skills/1c-db-dump-dt/scripts/db-dump-dt.ps1 -InfoBasePath "C:\Bases\MyDB" -UserName "Admin" -OutputFile "C:\backup\MyDB.dt"

# Серверная база
powershell.exe -NoProfile -File skills/1c-db-dump-dt/scripts/db-dump-dt.ps1 -InfoBaseServer "srv01" -InfoBaseRef "MyApp_Dev" -UserName "Admin" -Password "secret" -OutputFile "MyApp_Dev.dt"
```
