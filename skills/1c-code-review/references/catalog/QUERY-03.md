# QUERY-03. Отсутствие ПЕРВЫЕ в выбирающем запросе

## Идентификатор и группа

Идентификатор: `QUERY-03`
Группа: `QUERY` (язык запросов)
Псевдоним: п.5 (anti_patterns.md)

## Важность

Major

## Триггер

Запрос без ПЕРВЫЕ читает таблицу целиком, когда обработка использует часть строк

## Почему дефект

База возвращает и код разбирает все строки таблицы, хотя нужна часть: время и память тратятся на строки, которые будут отброшены.

## Законная форма

Запрос без ПЕРВЫЕ, которому нужны все строки: полная выборка для отчета или записи набора.

```bsl
"ВЫБРАТЬ
|    Поступления.Ссылка КАК Ссылка
|ИЗ
|    Документ.ПоступлениеТоваровУслуг КАК Поступления"
```

законная форма добавлена 2026-09-21

## Как чинить

Если обработка останавливается на первых строках - добавь ПЕРВЫЕ N; если часть строк задается условием - перенеси условие в ГДЕ.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Чтение таблицы целиком дефектно только когда обработка использует часть строк; границу задает замысел обработки.
