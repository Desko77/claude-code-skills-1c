# MODEL-15. Присваивание примитива полю ссылочного типа

## Идентификатор и группа

Идентификатор: `MODEL-15`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Полю ссылочного типа присваивается примитив: пустая строка, ноль или булево

## Почему дефект

Ссылочное поле требует значение ссылочного типа или Неопределено (для составного типа): присваивание примитива падает при записи объекта ошибкой преобразования типа либо дает неработающее значение, которое проявляется позже в сравнениях и соединениях.

## Законная форма

Пустое значение ссылочного поля - пустая ссылка через менеджер типа; очистка составного поля - Неопределено.

```bsl
Документ.Контрагент = Справочники.Контрагенты.ПустаяСсылка();
Документ.Основание = Документы.Заказ.ПустаяСсылка();
```

## Как чинить

Замени примитив пустой ссылкой типа: Справочники.<Имя>.ПустаяСсылка(), Документы.<Имя>.ПустаяСсылка(). Для составного типа с Неопределено очищай значением Неопределено, только если тип поля его допускает.
