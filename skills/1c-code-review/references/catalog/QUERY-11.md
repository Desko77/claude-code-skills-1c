# QUERY-11. Отбор в настройках СКД вместо условия набора данных

## Идентификатор и группа

Идентификатор: `QUERY-11`
Группа: `QUERY` (язык запросов)

## Важность

Minor

## Триггер

Ограничение выборки задано отбором настроек СКД, текст запроса набора без условия

## Почему дефект

Отбор настроек применяется к результату запроса: весь объем читается из базы и только потом фильтруется.

## Законная форма

Пользовательский отбор по полям, которых нет в тексте запроса (дополнительно вычисленные поля отчета): в тексте запроса условие задать нельзя.

```bsl
// Отбор по вычисленному полю ОтклонениеВПроцентах - его нет в тексте запроса
Настройки.Отбор.Добавить("ОтклонениеВПроцентах");
```

законная форма добавлена 2026-09-21

## Как чинить

Перенеси условия по полям источника в текст запроса набора данных (ГДЕ Период >= &НачалоПериода); в настройках остаются только пользовательские отборы по вычисляемым полям.
