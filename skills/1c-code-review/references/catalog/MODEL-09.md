# MODEL-09. Сборка выборки в массив вручную

## Идентификатор и группа

Идентификатор: `MODEL-09`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Minor

## Триггер

Выборка запроса в цикле собирается в массив структур с теми же полями, что и список полей запроса

## Почему дефект

Состав полей задублирован: имена перечислены в тексте запроса и повторены при сборке структур. Изменение списка полей правится в двух местах; встроенный метод Выгрузить() делает то же одним вызовом.

## Законная форма

Таблица значений с полями результата строится одним вызовом Выгрузить().

```bsl
Функция ТоварыДокумента(Ссылка)
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ
        |    Товары.Номенклатура КАК Номенклатура,
        |    Товары.Количество КАК Количество
        |ИЗ
        |    Документ.Поступление.Товары КАК Товары
        |ГДЕ
        |    Товары.Ссылка = &Ссылка";
    Запрос.УстановитьПараметр("Ссылка", Ссылка);
    РезультатЗапроса = Запрос.Выполнить();
    Возврат РезультатЗапроса.Выгрузить();
КонецФункции
```

## Как чинить

Замени цикл со сборкой структур на РезультатЗапроса.Выгрузить(): состав полей задается один раз в тексте запроса. Ручная сборка нужна только когда структура на выходе отличается от полей запроса.
