# TXN-01. НачатьТранзакцию внутри Попытка

## Идентификатор и группа

Идентификатор: `TXN-01`
Группа: `TXN` (транзакции и блокировки)
Псевдоним: п.8 (anti_patterns.md)

## Важность

Major

## Триггер

НачатьТранзакцию() вызывается внутри блока Попытка

## Почему дефект

Если ошибка произошла до открытия транзакции, Исключение вызовет ОтменитьТранзакцию() несуществующей транзакции: исходная ошибка будет заменена ошибкой отмены, настоящий отказ потерян.

## Законная форма

Транзакция открывается до Попытки, между ними нет операторов; отмена в Исключении корректна при любом отказе.

```bsl
НачатьТранзакцию();

Попытка
    Документ.Записать(РежимЗаписиДокумента.Проведение);
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

## Как чинить

Переставь НачатьТранзакцию() до Попытка; смежные требования шаблона - карточки TXN-02, TXN-03, TXN-04, TXN-05.
