# SEC-05. Неэкранированная вставка внешней строки в HTML

## Идентификатор и группа

Идентификатор: `SEC-05`
Группа: `SEC` (безопасность)

## Важность

Major

## Триггер

Строка из внешних данных конкатенацией собирается в HTML-документ или поле HTML формы

## Почему дефект

Внедрение разметки и скрипта в отображение (XSS): внешняя строка становится частью исполняемого документа веб-клиента.

## Законная форма

Вывод внешней строки в обычное поле формы: значение отображается как текст, разметка не интерпретируется.

```bsl
Объект.Комментарий = ВнешнийТекст;  // поле формы показывает текст как есть
```

законная форма добавлена 2026-09-21

## Как чинить

Для HTML экранируй разметку внешних строк перед вставкой; предпочтительно выводить текст полями формы, а HTML-поля не заполнять данными пользователей.
