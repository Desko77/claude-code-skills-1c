# MODEL-21. ТекущаяДата вместо ТекущаяДатаСеанса

## Идентификатор и группа

Идентификатор: `MODEL-21`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Серверный код датирует бизнес-операцию вызовом ТекущаяДата() без параметров

## Почему дефект

ТекущаяДата() возвращает время сервера без приведения к часовому поясу сеанса: при сервере в другом поясе документ получает дату, отличающуюся от местного времени пользователя на часы. Граница дня смещается: операции, выполненные вечером, попадают в следующий или предыдущий период, отчеты по дате теряют записи. Клиентский вызов ТекущаяДата() возвращает время клиента и тоже расходится с датой данных на сервере.

## Законная форма

Нужна именно дата и время компьютера: аппаратный журнал, метка файла, пауза измерения - с комментарием, почему часовой пояс сеанса не подходит.

```bsl
&НаСервере
Процедура УстановитьПериод()
    ДатаНачала = НачалоДня(ТекущаяДатаСеанса());
КонецПроцедуры
```

## Как чинить

Замени на ТекущаяДатаСеанса() везде, где дата участвует в бизнес-данных: реквизиты документов, границы периодов, отборы. Для чисто технических меток оставь ТекущаяДата() с комментарием.
