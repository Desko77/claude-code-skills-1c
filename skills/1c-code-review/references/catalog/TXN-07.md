# TXN-07. Блокировка после чтения

## Идентификатор и группа

Идентификатор: `TXN-07`
Группа: `TXN` (транзакции и блокировки)

## Важность

Major

## Триггер

БлокировкаДанных устанавливается после чтения данных, по которым принимается решение

## Почему дефект

Между чтением и блокировкой другой сеанс успевает изменить данные: решение принимается по устаревшему значению, контроль остатка или номера не действует.

## Законная форма

Чтение до блокировки допустимо для данных, которые не влияют на решение: блокируются остатки, читается текст сообщения.

```bsl
ПредставлениеОперации = СтрШаблон(НСтр("ru = 'Списание по складу %1'"), Склад);
Блокировка = Новый БлокировкаДанных;
ЭлементБлокировки = Блокировка.Добавить("РегистрНакопления.ТоварыНаСкладах");
ЭлементБлокировки.УстановитьЗначение("Склад", Склад);
ЭлементБлокировки.Режим = РежимБлокировкиДанных.Исключительный;
Блокировка.Заблокировать();
Остаток = ПрочитатьОстаток(Склад);
```

законная форма добавлена 2026-09-21

## Как чинить

Ставь блокировку до чтения, по которому принимается решение; после Заблокировать() данные перечитываются, решение принимается по защищенному состоянию.
