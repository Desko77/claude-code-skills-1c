# SEC-01. Конкатенация в тексте запроса вместо параметра

## Идентификатор и группа

Идентификатор: `SEC-01`
Группа: `SEC` (безопасность)

## Важность

Critical

## Триггер

Значение подставляется в текст запроса сложением строк вместо параметра

## Почему дефект

Внедрение произвольного текста в запрос: значение управляет выполняемым текстом, злоумышленник меняет условие и читает или меняет данные за пределами отбора.

## Законная форма

Сложение строки допустимо для имени таблицы из метаданных: имя приходит из Метаданные(), а не из входных данных; значения передаются только параметрами.

```bsl
ИмяТаблицы = "Справочник." + МетаданныеОбъекта.Имя;
Запрос.Текст =
"ВЫБРАТЬ " + ИмяТаблицы + ".Ссылка КАК Ссылка
|ИЗ " + ИмяТаблицы + " КАК Таблица
|ГДЕ Таблица.Ссылка = &Ссылка";
Запрос.УстановитьПараметр("Ссылка", Ссылка);
```

## Как чинить

Все значения передавай параметрами: &Параметр и УстановитьПараметр; текст запроса не строится из данных.
