# MODEL-10. Ключ соответствия склейкой значений в строку

## Идентификатор и группа

Идентификатор: `MODEL-10`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Ключ соответствия строится склейкой нескольких значений в строку через разделитель

## Почему дефект

Если разделитель встречается внутри значения, разные комбинации значений дают одну строку-ключ: соответствие молча перезаписывает запись первой комбинации данными второй.

## Законная форма

Составной ключ - вложенные соответствия по каждому полю ключа либо таблица значений с индексом по нескольким колонкам ключа и поиском Найти или НайтиСтроки. Структуру ключом соответствия не используй: соответствие сравнивает структуры по ссылке, и вновь созданная структура никогда не найдет запись.

```bsl
Остатки = Новый ТаблицаЗначений;
Остатки.Колонки.Добавить("Номенклатура");
Остатки.Колонки.Добавить("Склад");
Остатки.Колонки.Добавить("Количество");
Остатки.Индексы.Добавить("Номенклатура, Склад");
НайденныеСтроки = Остатки.НайтиСтроки(
    Новый Структура("Номенклатура, Склад", Товар, Склад));
```

## Как чинить

Замени строковую склейку вложенными соответствиями по каждому полю ключа либо таблицей значений с индексом по колонкам ключа (Индексы.Добавить("Номенклатура, Склад")) и поиском Найти или НайтиСтроки по структуре значений ключа.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Склейка ключа соответствия имеет законные случаи (составной ключ); дефектом становится по смыслу использования.
