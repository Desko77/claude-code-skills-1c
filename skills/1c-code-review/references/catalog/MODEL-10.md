# MODEL-10. Ключ соответствия склейкой значений в строку

## Идентификатор и группа

Идентификатор: `MODEL-10`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Ключ соответствия строится склейкой нескольких значений в строку через разделитель

## Почему дефект

Если разделитель встречается внутри значения, разные комбинации значений дают одну строку-ключ: соответствие молча перезаписывает запись первой комбинации данными второй. Ключ-структура сравнивается по составу и значениям полей и от разделителя не зависит.

## Законная форма

Составной ключ - структура с именованными полями: соответствие сравнивает структуры по составу и значениям полей.

```bsl
Ключ = Новый Структура("Номенклатура, Склад",
    Строка.Номенклатура, Строка.Склад);
Остатки.Вставить(Ключ, Строка.Количество);
```

## Как чинить

Замени строковую склейку ключом-структурой с полями по числу значений ключа. Если ключей много и нужен перебор - используй таблицу значений с индексированием по полям ключа.
