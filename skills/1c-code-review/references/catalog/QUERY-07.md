# QUERY-07. Прямое соединение с виртуальной таблицей

## Идентификатор и группа

Идентификатор: `QUERY-07`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

В разделе ИЗ соединение выполняется напрямую с виртуальной таблицей

## Почему дефект

Виртуальная таблица в соединении вычисляется по полному срезу значений без индекса по ключу соединения: план обходит все ее строки.

## Законная форма

Виртуальная таблица - единственный источник запроса без соединения: вычисляется один раз по своим параметрам.

```bsl
"ВЫБРАТЬ
|    Остатки.Номенклатура КАК Номенклатура,
|    Остатки.КоличествоОстаток КАК Остаток
|ИЗ
|    РегистрНакопления.ТоварыНаСкладах.Остатки(&Дата,) КАК Остатки"
```

## Как чинить

Вынеси виртуальную таблицу в временную таблицу (ПОМЕСТИТЬ, ИНДЕКСИРОВАТЬ ПО ключу соединения) и соединяй основной запрос с ней.
