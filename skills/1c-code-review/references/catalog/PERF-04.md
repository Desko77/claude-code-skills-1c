# PERF-04. Вложенный перебор коллекций вместо индекса

## Идентификатор и группа

Идентификатор: `PERF-04`
Группа: `PERF` (производительность)
Псевдоним: п.10 (anti_patterns.md)

## Важность

Minor

## Триггер

Два вложенных цикла ищут совпадение ключей между коллекциями

## Почему дефект

O(n2) сравнений: на больших коллекциях время растет квадратично, хотя совпадение находится за один проход по словарю.

## Законная форма

Вложенный перебор, где внутренний цикл обходит подчиненные строки той же внешней строки, а не ищет по всей второй коллекции.

```bsl
Для Каждого Группа Из Группы Цикл
    Для Каждого Подчиненная Из Группа.Строки Цикл
        ОбработатьСтроку(Подчиненная);
    КонецЦикла;
КонецЦикла;
```

законная форма добавлена 2026-09-21

## Как чинить

Построй Соответствие ключ - строка по второй коллекции одним проходом, затем одним проходом по первой коллекции получай совпадения за O(1).
