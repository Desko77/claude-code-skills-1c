# FORM-01. Переменная с именем реквизита формы

## Идентификатор и группа

Идентификатор: `FORM-01`
Группа: `FORM` (управляемые формы)

## Важность

Critical

## Триггер

Локальная переменная объявлена с именем реквизита формы и получает значение

## Почему дефект

В модуле формы имя без объявления разрешается в реквизит формы: присваивание пишет в реквизит и уходит в данные формы, а чтение возвращает значение реквизита. Код, рассчитывающий на локальную переменную, молча меняет данные формы; при отказе операции измененное значение остается в реквизите.

## Законная форма

Имена локальных переменных отличаются от имен реквизитов формы.

## Как чинить

Переименуй локальную переменную так, чтобы ее имя не совпадало с реквизитами формы (НайденныйКонтрагент вместо Контрагент). Список реквизитов формы - в редакторе формы; для уверенности объявляй переменные ключевым словом Перем.
