# MODEL-08. Присваивание свойству ПараметрыЗаписиJSON

## Идентификатор и группа

Идентификатор: `MODEL-08`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

У объекта ПараметрыЗаписиJSON, созданного без аргументов, значение задается присваиванием свойству

## Почему дефект

Свойства ПараметрыЗаписиJSON (СимволыОтступа, ПереносСтрок и другие) доступны только для чтения; значения задаются аргументами конструктора. Присваивание падает ошибкой "Поле объекта недоступно для записи" при первом выполнении.

## Законная форма

Значения задаются аргументами конструктора ПараметрыЗаписиJSON; отдельных присваиваний нет.

```bsl
Параметры = Новый ПараметрыЗаписиJSON(, СимволыОтступа.Табуляция);
Запись = Новый ЗаписьJSON;
Запись.УстановитьСтроку(, Параметры);
```

## Как чинить

Перенеси значения в конструктор: Новый ПараметрыЗаписиJSON(<ПереносСтрок>, <СимволыОтступа>). Присваивания свойствам после создания убери.
