# QUERY-06. Соединение с подзапросом

## Идентификатор и группа

Идентификатор: `QUERY-06`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

В разделе ИЗ соединение выполняется с вложенным ВЫБРАТЬ в скобках

## Почему дефект

Подзапрос в операнде соединения не может быть проиндексирован: для каждой строки внешней таблицы внутренняя выборка просматривается без индекса.

## Законная форма

Вложенный ВЫБРАТЬ в роли источника временной таблицы: пакет выполняет его один раз в ПОМЕСТИТЬ, соединение идет с материализованной таблицей.

```bsl
"ВЫБРАТЬ
|    Товары.Ссылка КАК Заказ,
|    СУММА(Товары.Сумма) КАК Сумма
|ПОМЕСТИТЬ ИтогиТоваров
|ИЗ
|    Документ.Заказ.Товары КАК Товары
|СГРУППИРОВАТЬ ПО
|    Товары.Ссылка
|ИНДЕКСИРОВАТЬ ПО
|    Заказ"
```

законная форма добавлена 2026-09-21

## Как чинить

Вынеси подзапрос в временную таблицу с ИНДЕКСИРОВАТЬ ПО по ключу соединения и соединяйся с ней.
