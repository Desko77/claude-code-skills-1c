# TXN-09. Разный порядок захвата блокировок

## Идентификатор и группа

Идентификатор: `TXN-09`
Группа: `TXN` (транзакции и блокировки)

## Важность

Major

## Триггер

Две операции захватывают одни и те же ресурсы в разном порядке

## Почему дефект

Взаимная блокировка: каждая операция держит ресурс и ждет ресурс, который держит другая; сеансы зависают до таймаута транзакции.

## Законная форма

Порядок захвата одинаков во всех операциях проекта: сначала товары, затем взаиморасчеты - в обеих процедурах.

```bsl
// Обе операции: сначала ТоварыНаСкладах, затем РасчетыСКонтрагентами
Блокировка = Новый БлокировкаДанных;
Блокировка.Добавить("РегистрНакопления.ТоварыНаСкладах");
Блокировка.Добавить("РегистрНакопления.РасчетыСКонтрагентами");
Блокировка.Заблокировать();
```

законная форма добавлена 2026-09-21

## Как чинить

Зафиксируй порядок захвата соглашением проекта и приведи все операции к нему: блокировки одного набора таблиц берутся в одном порядке.
