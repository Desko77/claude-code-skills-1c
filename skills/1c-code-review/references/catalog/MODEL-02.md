# MODEL-02. Замещающая запись набора записей с неполным отбором

## Идентификатор и группа

Идентификатор: `MODEL-02`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Critical

## Триггер

Набор записей с замещающей записью Записать(Истина) получает отбор не по всем ключевым измерениям регистра

## Почему дефект

Замещающая запись удаляет все записи, подходящие под отбор набора, и пишет новые. Отбор по части ключевых измерений стирает и записи с другими значениями пропущенных измерений: данные других контекстов теряются без следа в журнале, восстановление - только выгрузкой или обменом.

## Законная форма

Отбор набора задан по всем ключевым измерениям регистра (Период, Валюта, Склад): замещение затрагивает только записи этой комбинации.

```bsl
Набор = РегистрыСведений.ЦеныСкладов.СоздатьНаборЗаписей();
Набор.Отбор.Период.Установить(Период);
Набор.Отбор.Валюта.Установить(Валюта);
Набор.Отбор.Склад.Установить(Склад);
Запись = Набор.Добавить();
Запись.Период = Период;
Запись.Валюта = Валюта;
Запись.Склад = Склад;
Запись.Курс = Курс;
Набор.Записать(Истина);
```

## Как чинить

Добавь в отбор значения всех ключевых измерений регистра. Для частичной замены - прочитай набор, измени нужные записи и запиши его целиком по полному отбору; дозапись без стирания - Записать(Ложь).
