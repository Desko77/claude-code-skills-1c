# EXT-03. Имя метода расширения без префикса

## Идентификатор и группа

Идентификатор: `EXT-03`
Группа: `EXT` (расширения конфигурации)

## Важность

Minor

## Триггер

Процедура расширения названа без префикса расширения

## Почему дефект

Конфликт имен с другими расширениями и типовым кодом при наложении: одно имя - два владельца, платформа разрешает конфликт отказом загрузки.

## Законная форма

Имя без префикса у локальной служебной процедуры модуля расширения: имя не пересекается с типовым кодом и не покидает модуль.

```bsl
Процедура ЗаполнитьСтрокиЛокально(Строки)
    // Служебная процедура модуля расширения, снаружи не вызывается.
КонецПроцедуры
```

законная форма добавлена 2026-09-21

## Как чинить

Добавляй префикс расширения ко всем именам, видимым снаружи модуля: Расш1_ДополнительнаяПроверка.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Отсутствие префикса расширения в имени процедуры требует знания префикса и принадлежности модуля расширению; текст модуля без контекста проекта этого не дает.
