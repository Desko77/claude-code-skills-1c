# QUERY-15. Временная таблица без индекса перед соединением

## Идентификатор и группа

Идентификатор: `QUERY-15`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Временная таблица помещена без ИНДЕКСИРОВАТЬ ПО и в том же пакете участвует в соединении по этим полям

## Почему дефект

Соединение с неиндексированной временной таблицей выполняется полным перебором строк на каждую строку внешней части: платформа не строит индекс по временной таблице сама. ИНДЕКСИРОВАТЬ ПО полям соединения убирает перебор.

## Законная форма

Временная таблица, участвующая в соединении, индексируется по полям связи.

```bsl
ВЫБРАТЬ
    Оплаты.Заказ КАК Заказ,
    СУММА(Оплаты.Сумма) КАК Сумма
ПОМЕСТИТЬ ВТИтогиОплат
ИЗ
    Документ.Оплата КАК Оплаты
СГРУППИРОВАТЬ ПО
    Оплаты.Заказ
ИНДЕКСИРОВАТЬ ПО
    Заказ
;
ВЫБРАТЬ
    Заказы.Ссылка КАК Ссылка
ИЗ
    Документ.Заказ КАК Заказы
        ЛЕВОЕ СОЕДИНЕНИЕ ВТИтогиОплат КАК Итоги
        ПО Заказы.Ссылка = Итоги.Заказ
```

## Как чинить

Добавь после выборки во временную таблицу секцию ИНДЕКСИРОВАТЬ ПО с полями, по которым таблица соединяется или отбирается в следующих пакетах.
