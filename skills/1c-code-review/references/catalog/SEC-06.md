# SEC-06. Выполнение внешнего кода без изоляции

## Идентификатор и группа

Идентификатор: `SEC-06`
Группа: `SEC` (безопасность)

## Важность

Critical

## Триггер

На сервере выполняется код или программа, не входящая в конфигурацию: Выполнить или Вычислить над строкой, собранной из внешних данных; подключение внешней компоненты; запуск внешнего приложения или команды системы - без безопасного режима и без проверки входных данных

## Почему дефект

Строка, собранная из параметров пользователя или данных внешнего файла, выполняется с правами серверного сеанса: внедренный фрагмент получает доступ ко всей базе. Внешняя компонента и запускаемое приложение исполняются в контексте сервера без ограничений: загрузка вредоносного кода или утечка данных не контролируются конфигурацией. Отключение безопасного режима ради выполнения такой операции открывает тот же канал для остальных сеансов.

## Законная форма

Выполнение кода из доверенного источника: строка собрана из констант модуля и не содержит внешних данных, либо внешний код подключается средствами БСП после проверки поставщика, либо вызов окружен УстановитьБезопасныйРежим(Истина) с возвратом исходного режима после.

```bsl
&НаСервере
Процедура ВыполнитьПересчет(Формула)
    Если Не ДопустимыеСимволыФормулы(Формула) Тогда
        ВызватьИсключение "Недопустимые символы в формуле";
    КонецЕсли;
    Результат = Вычислить(Формула);
КонецПроцедуры
```

## Как чинить

Убери выполнение собранной строки: замени на разбор данных и вызов типовых методов. Внешние данные сначала проверяй по составу и типам (SEC-04). Компоненту подключай через механизм БСП с включенным безопасным режимом; для Выполнить и Вычислить над доверенным шаблоном - УстановитьБезопасныйРежим(Истина) перед вызовом и восстановление режима после.
