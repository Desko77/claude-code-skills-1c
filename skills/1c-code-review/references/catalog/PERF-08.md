# PERF-08. Обращение к внешнему ресурсу без таймаута

## Идентификатор и группа

Идентификатор: `PERF-08`
Группа: `PERF` (производительность)

## Важность

Major

## Триггер

Создается соединение с внешним ресурсом - HTTPСоединение, FTPСоединение, WSОпределения, WSПрокси, ИнтернетПочтовыйПрофиль - или вызывается ожидание завершения фонового задания без ограничения времени ожидания

## Почему дефект

Вызов без таймаута ждет ответа неограниченно: недоступный внешний сервис блокирует поток или сеанс до разрыва соединения самой сетью. На сервере занятый поток останавливает обработку других сеансов, на клиенте форма зависает без сообщения. Ожидание фонового задания без таймаута держит вызывающий сеанс до завершения задания любой длительности.

## Законная форма

Таймаут задан явным значением, согласованным с регламентом (для интеграций - в настройках обмена), включая нулевое только осознанно с комментарием о немедленном отказе.

```bsl
Соединение = Новый HTTPСоединение(
    "example.com", 443,,, Неопределено, 30);
Ответ = Соединение.Получить(Запрос);
```

## Как чинить

Передай таймаут параметром конструктора соединения или метода ожидания. Значение возьми из настроек интеграции; для WSПрокси и WSОпределения таймаут задается при создании, для ожидания фонового задания - параметром метода ожидания.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: признак - отсутствие параметра в многострочном вызове конструктора; текстовый детектор по строке не отличает позицию таймаута, в EDT семантической проверки аргументов конструкторов нет.
