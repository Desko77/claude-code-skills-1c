# CLIENT-03. Серверный вызов в цикле на клиенте

## Идентификатор и группа

Идентификатор: `CLIENT-03`
Группа: `CLIENT` (клиент-серверное взаимодействие)

## Важность

Major

## Триггер

В цикле клиентской процедуры вызывается серверная функция

## Почему дефект

N сетевых переходов: задержка операции растет на число итераций цикла, каждая итерация платит за сериализацию параметров и результата.

## Законная форма

Цикл выполняется на сервере внутри одного вызова: клиент обращается к серверу один раз, перебор строк идет в серверной функции.

```bsl
&НаКлиенте
Процедура ОбработатьСтроки(Команда)
    Результаты = ОбработатьСтрокиНаСервере(Товары);
КонецПроцедуры

&НаСервереБезКонтекста
Функция ОбработатьСтрокиНаСервере(Строки)
    Результаты = Новый Массив;
    Для Каждого Строка Из Строки Цикл
        Результаты.Добавить(ОбработатьСтроку(Строка));
    КонецЦикла;
    Возврат Результаты;
КонецФункции
```

## Как чинить

Перенеси цикл на сервер: один вызов получает всю коллекцию, перебирает ее и возвращает массив результатов.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: ServerCallsInFormEvents покрывает только события ПриАктивизацииСтроки и НачалоВыбора; вызов серверной функции в произвольном цикле клиентского кода диагностиками не выделяется.
