# MODEL-03. Обход API подсистемы дополнительных свойств

## Идентификатор и группа

Идентификатор: `MODEL-03`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Виды характеристик создаются программно или регистры подсистемы свойств пишутся напрямую, минуя ее программный интерфейс

## Почему дефект

Состав и структура регистров и видов характеристик подсистемы свойств - внутренняя реализация БСП. Программно созданные виды не отображаются в интерфейсе управления свойствами и теряют настройки при обновлении; прямая запись в регистры рассинхронизирует данные подсистемы с ее таблицами.

## Законная форма

Код читает и устанавливает свойства только через экспортные функции подсистемы; виды характеристик создает разработчик в метаданных, без программного создания.

```bsl
Свойства = УправлениеСвойствами.ЗначенияСвойств(Объект);
СкладХранения = Свойства.СкладХранения;
```

## Как чинить

Убери СоздатьЭлемент() у менеджера видов характеристик и прямые записи в регистры подсистемы. Чтение и запись значений свойств - через функции общего модуля подсистемы (УправлениеСвойствами), состав видов - в метаданных конфигурации.
