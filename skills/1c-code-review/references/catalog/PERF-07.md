# PERF-07. Временный файл не удален

## Идентификатор и группа

Идентификатор: `PERF-07`
Группа: `PERF` (производительность)

## Важность

Major

## Триггер

Код получает имя временного файла или строит свой путь в каталоге временных файлов, пишет туда и завершает работу без удаления

## Почему дефект

Временные файлы накапливаются: каталог временных файлов растет до исчерпания места на диске сервера, обслуживание без простоев невозможно. Файлы, созданные собственным кодом в каталоге временных файлов, платформа не отслеживает; полагаться на автоматическую очистку при перезапуске нельзя - перезапуск рабочего процесса не гарантирован, а между перезапусками место занимается.

## Законная форма

Файл удаляется сразу после использования, в том числе при ошибке обработки; либо имя получено через ПолучитьИмяВременногоФайла и файл остается под контролем платформы на время сеанса при обосновании в комментарии.

```bsl
ИмяФайла = ПолучитьИмяВременногоФайла("xml");
Попытка
    Данные.Записать(ИмяФайла);
    ПрочитатьДанные(ИмяФайла);
Исключение
    УдалитьФайлы(ИмяФайла);
    ВызватьИсключение ОписаниеОшибки();
КонецПопытки
УдалитьФайлы(ИмяФайла);
```

## Как чинить

Обработку файла оберни так, чтобы удаление выполнялось и при ошибке: выделенный блок с удалением после использования или отдельный метод очистки в исключении. Для промежуточных данных предпочитай ПолучитьИмяВременногоФайла и хранилище значений вместо собственного пути в каталоге временных файлов.
