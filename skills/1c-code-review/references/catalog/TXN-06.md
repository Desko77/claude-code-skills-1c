# TXN-06. Своя транзакция в обработчике записи

## Идентификатор и группа

Идентификатор: `TXN-06`
Группа: `TXN` (транзакции и блокировки)

## Важность

Major

## Триггер

Внутри ПередЗаписью, ПриЗаписи или ОбработкаПроведения вызывается НачатьТранзакцию()

## Почему дефект

Обработчик уже выполняется в транзакции записи платформы. Вложенного вызова не существует: платформа считает уровень вложенности, а отмена внутреннего уровня помечает испорченной всю внешнюю транзакцию.

## Законная форма

Обработчик записи пишет данные без своей транзакции: запись выполняется в транзакции платформы.

```bsl
Процедура ПриЗаписи(Отказ)
    Движения.Товары.Записать();
КонецПроцедуры
```

законная форма добавлена 2026-09-21

## Как чинить

Убери НачатьТранзакцию() из обработчика. Явная транзакция нужна только в вызывающем коде, который атомарно записывает несколько объектов.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:TXN-06 | static |

Обоснование чтения: Транзакция в обработчике события объекта диагностиками не выделяется; текстовый признак (имя процедуры и НачатьТранзакцию) закрывается lint.
