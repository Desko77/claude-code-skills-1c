# QUERY-01. Подзапрос в списке полей SELECT

## Идентификатор и группа

Идентификатор: `QUERY-01`
Группа: `QUERY` (язык запросов)
Псевдоним: п.3 (anti_patterns.md)

## Важность

Critical

## Триггер

В списке полей SELECT стоит вложенный ВЫБРАТЬ в скобках

## Почему дефект

Коррелированный подзапрос выполняется для каждой строки внешней выборки: N строк внешней таблицы дают N+1 выполнение внутреннего запроса.

## Законная форма

Некоррелированный подзапрос: внутренний ВЫБРАТЬ не ссылается на поля внешней таблицы и выполняется один раз.

```bsl
"ВЫБРАТЬ
|    (ВЫБРАТЬ ПЕРВЫЕ 1 Курсы.Курс
|     ИЗ РегистрСведений.КурсыВалют КАК Курсы
|     ГДЕ Курсы.Валюта = &Валюта) КАК Курс
|ИЗ
|    Справочник.Валюты КАК Валюты"
```

законная форма добавлена 2026-09-21

## Как чинить

Вынеси итоги во временную таблицу (ПОМЕСТИТЬ с ИНДЕКСИРОВАТЬ ПО по ключу соединения) и соедини с ней: одна прохода агрегата вместо N.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:QUERY-01 | static |

Обоснование чтения: Вложенный ВЫБРАТЬ в списке полей синтаксически корректен: валидация запроса проходит, диагностики bsl-language-server на такой случай нет. Текстовый признак закрывается lint.
