# SEC-04. Внешние данные без валидации

## Идентификатор и группа

Идентификатор: `SEC-04`
Группа: `SEC` (безопасность)

## Важность

Major

## Триггер

Данные из файла, HTTP-сервиса или другой базы используются без проверки структуры и типов

## Почему дефект

Недоверенные данные ломают обработку и попадают в базу: отсутствующее поле дает ошибку времени выполнения, значение неверного типа - искаженный результат.

## Законная форма

Работа с уже проверенными данными: валидация выполнена на входе модуля, глубже по стеку повторная проверка не нужна.

```bsl
Функция ЗаписатьПроверенныйОтвет(Ответ)
    // Ответ проверен на входе модуля: поля Сумма и Номер есть, типы сверены.
    СтрокаРегистра.Сумма = Ответ.Сумма;
    СтрокаРегистра.Номер = Ответ.Номер;
КонецФункции
```

законная форма добавлена 2026-09-21

## Как чинить

Проверяй на границе: обязательные поля (Свойство), типы (ТипЗнч), диапазоны значений; непрошедшие данные отвергаются с журналом регистрации.
