# PROC-02. Вывод о компиляции по загрузке конфигурации

## Идентификатор и группа

Идентификатор: `PROC-02`
Группа: `PROC` (дефекты процесса ответа)

## Важность

Major

## Триггер

Вывод "код компилируется" сделан по загрузке или выгрузке конфигурации, валидатору XML или анализатору, который модули не компилирует

## Почему дефект

Загрузка конфигурации и проверка XML подтверждают структуру файлов, а не компиляцию модулей: модуль с синтаксической ошибкой загружается вместе с остальными, ошибка проявляется при первом обращении в работе. Вывод о компиляции таким способом не обоснован.

## Законная форма

Вывод о компиляции дает синтаксический контроль модулей: проверка модуля в Конфигураторе, ошибки проекта EDT, синтаксический анализатор - со следом прогона.

```json
{
    "claim": "модуль компилируется",
    "run": "get_project_errors",
    "object": "Catalog.Товары.ObjectModule",
    "errors": 0
}
```

## Как чинить

Проверяй компиляцию тем, что ее проверяет: синтаксический контроль модуля или ошибки проекта EDT, с записью команды и результата. Загрузка и выгрузка конфигурации как довод компиляции не заявляются.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Дефект процесса ответа: вывод о компиляции по инструменту, который модули не компилирует. Проверяется сверкой с трейсом инструментов.
