# QUERY-14. Коррелированный подзапрос в разделе ГДЕ

## Идентификатор и группа

Идентификатор: `QUERY-14`
Группа: `QUERY` (язык запросов)

## Важность

Critical

## Триггер

В разделе ГДЕ стоит вложенный ВЫБРАТЬ, ссылающийся на поле внешнего запроса

## Почему дефект

Подзапрос, связанный с полем внешнего запроса, вычисляется для каждой строки внешней таблицы: время растет как произведение объемов таблиц. Смежный случай - QUERY-01 (подзапрос в списке полей), механизм тот же.

## Законная форма

Набор значений подзапроса помещается во временную таблицу с индексом и соединяется явно.

```bsl
ВЫБРАТЬ
    Оплаты.Заказ КАК Заказ,
    Оплаты.Контрагент КАК Контрагент
ПОМЕСТИТЬ ВТОплаты
ИЗ
    Документ.Оплата КАК Оплаты
ИНДЕКСИРОВАТЬ ПО
    Контрагент
;
ВЫБРАТЬ
    Заказы.Ссылка КАК Ссылка
ИЗ
    Документ.Заказ КАК Заказы
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ ВТОплаты КАК Оплаты
        ПО Заказы.Контрагент = Оплаты.Контрагент
```

## Как чинить

Перепиши подзапрос из ГДЕ в явное соединение с временной таблицей: ПОМЕСТИТЬ выборку во временную таблицу, ИНДЕКСИРОВАТЬ ПО полю связи, затем СОЕДИНЕНИЕ по этому полю. Небольшой готовый набор - параметр В (&Список).
