# TXN-05. Нет ВызватьИсключение после отмены транзакции

## Идентификатор и группа

Идентификатор: `TXN-05`
Группа: `TXN` (транзакции и блокировки)

## Важность

Major

## Триггер

Блок Исключение кода с транзакцией завершается без ВызватьИсключение

## Почему дефект

Откат произошел, но ошибка не покинула процедуру: вызывающий код считает операцию прошедшей и строит дальнейшую работу на несостоявшемся результате.

## Законная форма

Попытка без транзакции, где Исключение завершает обработку осознанно: ошибка сообщена пользователю, операция прервана своим кодом.

```bsl
Попытка
    ПрочитатьФайлОбмена(ИмяФайла);
Исключение
    ОбщегоНазначения.СообщитьПользователю(
        НСтр("ru = 'Файл обмена не читается, загрузка прервана.'"));
    Возврат;
КонецПопытки;
```

законная форма добавлена 2026-09-21

## Как чинить

Добавь ВызватьИсключение последним оператором Исключения после отмены и логирования; без возбуждения откат молчит для вызывающего кода.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:TXN-05 | static |

Обоснование чтения: MissingCodeTryCatchEx ловит пустой блок Исключение, а не отсутствие ВызватьИсключение в непустом; текстовый признак закрывается lint.
