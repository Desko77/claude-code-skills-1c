# MODEL-04. Флаг ошибки вместо отмены операции

## Идентификатор и группа

Идентификатор: `MODEL-04`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Отказ операции возвращается выходным параметром-флагом или структурой результата, а вызывающий код продолжает работу без его проверки

## Почему дефект

Выходной параметр не останавливает вызывающий код: точка вызова, не проверившая флаг, работает с данными незавершенной операции. Ошибка не попадает в журнал регистрации и не откатывает транзакцию - отказ проглатывается.

## Законная форма

Отказ операции передается исключением: вызывающий код не может продолжить мимо него; выходные параметры остаются для данных, а не для решения о продолжении.

```bsl
Процедура ОтправитьДокумент(Документ)
    Если Не Документ.Проведен Тогда
        ВызватьИсключение "Документ не проведен: "
            + Строка(Документ);
    КонецЕсли;
    ОтправитьНаСервер(Документ);
КонецПроцедуры
```

## Как чинить

Замени выходной параметр-флаг на ВызватьИсключение с текстом ошибки; проверку в точке вызова убери - исключение проходит все уровни. Флаг допустим только для предупреждений, не влияющих на продолжение.
