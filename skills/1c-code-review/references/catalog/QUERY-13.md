# QUERY-13. Строковая колонка таблицы значений без квалификатора в параметре запроса

## Идентификатор и группа

Идентификатор: `QUERY-13`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Таблица значений со строковой колонкой без КвалификаторыСтроки передается параметром в запрос и соединяется с таблицей базы

## Почему дефект

Колонка без квалификатора имеет неограниченную длину: при соединении с полем таблицы ограниченной длины запрос не выполняется - платформа отвергает несовместимые типы колонок. Ошибка возникает на выполнении запроса, не при компиляции модуля.

## Законная форма

Строковая колонка, участвующая в соединении, создается с явной длиной через КвалификаторыСтроки.

```bsl
Квалификатор = Новый КвалификаторыСтроки(9);
ТипКода = Новый ОписаниеТипов("Строка",, Квалификатор);
Таблица = Новый ТаблицаЗначений;
Таблица.Колонки.Добавить("Код", ТипКода);
```

## Как чинить

Создай колонку с описанием типов, включающим КвалификаторыСтроки(<длина>) равной длине поля таблицы базы, с которым колонка соединяется. Убедись, что длины совпадают: несовпадение длины также ломает соединение.
