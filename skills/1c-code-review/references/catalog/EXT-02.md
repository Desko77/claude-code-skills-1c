# EXT-02. Нет ПродолжитьВызов в ИзменениеИКонтроль

## Идентификатор и группа

Идентификатор: `EXT-02`
Группа: `EXT` (расширения конфигурации)

## Важность

Critical

## Триггер

Метод с декоратором ИзменениеИКонтроль не вызывает ПродолжитьВызов()

## Почему дефект

Оригинальный метод не выполнится: типовая логика проведения или записи молча выпадает, данные остаются несогласованными.

## Законная форма

Перехватчики &Перед и &После: ПродолжитьВызов() там не вызывается вручную и не должен - оригинал выполняется платформой сам.

```bsl
&НаСервере
&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи()
    // Свой код; оригинал выполнится автоматически после процедуры.
КонецПроцедуры
```

## Как чинить

В &ИзменениеИКонтроль вызывай ПродолжитьВызов() для выполнения оригинала; изменения оформляй маркерами #Вставка и #Удаление.
