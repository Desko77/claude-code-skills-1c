# EXT-02. &Вместо без ПродолжитьВызов()

## Идентификатор и группа

Идентификатор: `EXT-02`
Группа: `EXT` (расширения конфигурации)

## Важность

Critical

## Триггер

Перехватчик &Вместо не вызывает ПродолжитьВызов(), и полная замена типового метода не заявлена в шапке как намеренная

## Почему дефект

Типовой метод не выполняется вовсе: проведение, запись, контроль заполнения типовой конфигурации молча выпадают, а проверки, которые вендор добавит в этот метод при обновлении, в перехват уже не попадут.

## Законная форма

Оригинал выполняется через ПродолжитьВызов() с теми же параметрами; свой код - до или после него. Полная замена без ПродолжитьВызов() допустима только с обоснованием в шапке, почему типовой метод выполнять нельзя. В &Перед и &После оригинал выполняет платформа, в &ИзменениеИКонтроль тело повторяет типовой метод с блоками #Вставка и #Удаление - ПродолжитьВызов() там не используется.

```bsl
&НаСервере
&Вместо("ОбработкаПроведения")
Процедура Расш1_ОбработкаПроведения(Отказ)
    ОбновитьРезерв(ЭтотОбъект);
    ПродолжитьВызов(Отказ);
КонецПроцедуры
```

## Как чинить

Добавь ПродолжитьВызов() с параметрами перехваченного метода в нужное место &Вместо; если типовой метод нужен целиком до или после своего кода - замени &Вместо на &Перед или &После; если нужно править тело - &ИзменениеИКонтроль с маркерами.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: WrongUseFunctionProceedWithCall ловит обратный случай: вызов ПродолжитьВызов вне &Вместо. Отсутствие вызова внутри перехватчика требует семантики расширения; семантическая проверка плагина - задача 4.4 плана контура качества.
