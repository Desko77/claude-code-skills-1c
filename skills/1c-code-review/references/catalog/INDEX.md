# Индекс каталога дефектов

Генерируется `tools/gen_catalog_index.py` по карточкам каталога; правится только
через карточки. Колонка Триггер - формулировка одной строкой; полные триггер,
законная форма и способ чинить - в карточке с идентичным именем.

| Идентификатор | Важность | Группа | Архетипы | Детекторы | Триггер |
|---------------|----------|--------|----------|-----------|---------|
| CLIENT-01 | Major | CLIENT | модуль формы, любой BSL | EDT: чтение; Конфигуратор: чтение | Из клиентской процедуры подряд вызывается несколько серверных функций для одной операции |
| CLIENT-02 | Major | CLIENT | модуль формы | EDT: чтение; Конфигуратор: чтение | Серверная функция модуля формы с директивой НаСервере не обращается к реквизитам формы |
| CLIENT-03 | Major | CLIENT | модуль формы, любой BSL | EDT: чтение; Конфигуратор: чтение | В цикле клиентской процедуры вызывается серверная функция |
| EXT-01 | Major | EXT | перехват в расширении | EDT: чтение; Конфигуратор: чтение | Тело заимствованной процедуры расширения изменено напрямую, без перехватчика |
| EXT-02 | Critical | EXT | перехват в расширении | EDT: чтение; Конфигуратор: чтение | Перехватчик &Вместо не вызывает ПродолжитьВызов(), и полная замена типового метода не заявлена в шапке как намеренная |
| EXT-03 | Minor | EXT | перехват в расширении | EDT: чтение; Конфигуратор: чтение | Процедура расширения названа без префикса расширения |
| EXT-04 | Major | EXT | изменение метаданных, права | EDT: чтение; Конфигуратор: чтение | В Rights.xml роли расширения есть блок прав вида Enum.ИмяПеречисления |
| MODEL-01 | Minor | MODEL | любой BSL | EDT: чтение; Конфигуратор: чтение | Более четырех уровней вложенности условий и циклов в одной процедуре |
| PERF-01 | Critical | PERF | запрос, любой BSL | EDT: чтение; Конфигуратор: чтение | В цикле создается Новый Запрос или выполняется Выполнить() на каждой итерации |
| PERF-02 | Critical | PERF | любой BSL, запрос | EDT: чтение; Конфигуратор: чтение | У ссылочной переменной подряд читается несколько реквизитов через точку |
| PERF-03 | Minor | PERF | любой BSL | EDT: чтение; Конфигуратор: чтение | В цикле вызывается функция с одинаковыми аргументами, результат не сохраняется |
| PERF-04 | Minor | PERF | любой BSL | EDT: чтение; Конфигуратор: чтение | Два вложенных цикла ищут совпадение ключей между коллекциями |
| QUERY-01 | Critical | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | В списке полей SELECT стоит вложенный ВЫБРАТЬ в скобках |
| QUERY-02 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Условие на измерение виртуальной таблицы стоит в ГДЕ, а не в параметрах таблицы |
| QUERY-03 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Запрос без ПЕРВЫЕ читает таблицу целиком, когда обработка использует часть строк |
| QUERY-04 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Через точку читается поле составного типа без ВЫРАЗИТЬ |
| QUERY-05 | Minor | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Из ссылки в списке полей читается Наименование только ради отображения |
| QUERY-06 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | В разделе ИЗ соединение выполняется с вложенным ВЫБРАТЬ в скобках |
| QUERY-07 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | В разделе ИЗ соединение выполняется напрямую с виртуальной таблицей |
| QUERY-08 | Major | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Условия одной таблицы в ГДЕ соединены через ИЛИ по разным полям |
| QUERY-09 | Minor | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Пакеты объединены через ОБЪЕДИНИТЬ без слова ВСЕ при отсутствии дубликатов |
| QUERY-10 | Major | QUERY | запрос, изменение метаданных | EDT: чтение; Конфигуратор: чтение | Условия ГДЕ заданы по полям, пропускающим первые поля индекса таблицы |
| QUERY-11 | Minor | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Ограничение выборки задано отбором настроек СКД, текст запроса набора без условия |
| QUERY-12 | Minor | QUERY | запрос | EDT: чтение; Конфигуратор: чтение | Из полей правой таблицы ЛЕВОГО СОЕДИНЕНИЯ значения читаются без ЕСТЬNULL |
| SEC-01 | Critical | SEC | права, запрос, любой BSL | EDT: чтение; Конфигуратор: чтение | Значение подставляется в текст запроса сложением строк вместо параметра |
| SEC-02 | Critical | SEC | права | EDT: чтение; Конфигуратор: чтение | УстановитьПривилегированныйРежим(Истина) или метод привилегированного общего модуля читает либо изменяет данные, состав которых задан параметрами от пользователя, и результат уходит пользователю или изменение делается от его имени - без явной проверки права до операции |
| SEC-03 | Critical | SEC | права, любой BSL | EDT: чтение; Конфигуратор: чтение | В коде встречается пароль, токен или ключ строковым литералом |
| SEC-04 | Major | SEC | любой BSL | EDT: чтение; Конфигуратор: чтение | Данные из файла, HTTP-сервиса или другой базы используются без проверки структуры и типов |

| TXN-03 | Major | TXN | транзакция | EDT: чтение; Конфигуратор: чтение | После ЗафиксироватьТранзакцию() внутри Попытка стоят еще операторы |
