# PERF-02. Чтение реквизитов по ссылке через точку

## Идентификатор и группа

Идентификатор: `PERF-02`
Группа: `PERF` (производительность)
Псевдоним: п.2 (anti_patterns.md)

## Важность

Critical

## Триггер

У ссылочной переменной подряд читается несколько реквизитов через точку

## Почему дефект

Каждое обращение через точку к ссылке читает объект целиком: три реквизита одной ссылки - три полные загрузки объекта из базы.

## Законная форма

Единичное обращение, когда нужен только один реквизит и других обращений к объекту нет: одна загрузка равна одному целевому запросу.

```bsl
ИНН = Контрагент.ИНН;
```

## Как чинить

Для нескольких реквизитов - ОбщегоНазначения.ЗначенияРеквизитовОбъекта (несколько реквизитов одной ссылки), ЗначениеРеквизитаОбъектов (один реквизит нескольких ссылок) или целевой запрос.
