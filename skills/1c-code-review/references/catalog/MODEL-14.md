# MODEL-14. Диспетчеризация значений без ветки Иначе

## Идентификатор и группа

Идентификатор: `MODEL-14`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Цепочка Если-ИначеЕсли из трех и более веток по значению или типу не имеет ветки Иначе

## Почему дефект

Значение вне перечисленных веток обрабатывается молча: код продолжает работу с неинициализированными данными или пропускает обязательное действие. Отказ невидим - ни сообщения, ни записи в журнале.

## Законная форма

Ветка Иначе обрабатывает неожидаемое значение явно: исключением или записью в журнал.

```bsl
Если ВидОперации = Перечисления.ВидыОпераций.Продажа Тогда
    ПровестиПродажу(Операция);
ИначеЕсли ВидОперации = Перечисления.ВидыОпераций.Возврат Тогда
    ПровестиВозврат(Операция);
Иначе
    ВызватьИсключение "Неизвестный вид операции: "
        + Строка(ВидОперации);
КонецЕсли;
```

## Как чинить

Добавь ветку Иначе с явной обработкой неожидаемого значения: ВызватьИсключение или ЗаписьЖурналаРегистрации с видом операции. Если набор значений закрыт и проверен до цепочки - перенеси проверку до нее.
