# PERF-09. Долгая операция без фонового задания

## Идентификатор и группа

Идентификатор: `PERF-09`
Группа: `PERF` (производительность)

## Важность

Major

## Триггер

Интерактивный вызов выполняет обработку, рассчитанную на большой объем данных: серверный метод формы или обработки в одном вызове обходит тысячи записей, строит большие отчеты, читает внешние сервисы - без запуска фонового задания и индикации прогресса

## Почему дефект

Сеанс пользователя занят на все время обработки: форма не отвечает, платформа разрывает соединение по таймауту простоя, результат теряется. Многократный запуск таких операций параллельно расходует пул потоков сервера и мешает другим сеансам. Прогресс и отмена недоступны: пользователь не видит состояния и не может прервать ошибочный запуск.

## Законная форма

Обработка заведомо малого и ограниченного объема: фиксированный отбор с оценкой числа строк, интерактивная операция над одной записью.

```bsl
&НаСервере
Процедура ПересчитатьСтроку(НомерСтроки)
    Строка = Объект.Товары[НомерСтроки];
    Строка.Сумма = Строка.Цена * Строка.Количество;
КонецПроцедуры
```

## Как чинить

Вынеси обработку в фоновое задание средствами БСП: ДлительныеОперации.ВыполнитьВФоне, ВыполнитьФункцию или ВыполнитьПроцедуру - форма запускает задание, показывает индикацию и получает оповещение о завершении. На сервере без БСП - ФоновыеЗадания.Выполнить с контролем завершения по таймауту.
