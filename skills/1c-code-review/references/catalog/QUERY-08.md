# QUERY-08. ИЛИ по разным полям в ГДЕ

## Идентификатор и группа

Идентификатор: `QUERY-08`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Условия одной таблицы в ГДЕ соединены через ИЛИ по разным полям

## Почему дефект

ИЛИ по разным полям не позволяет использовать индекс ни по одному из них: таблица читается целиком.

## Законная форма

ИЛИ по одному и тому же полю: эквивалентно В (&Значение1, &Значение2), индекс по полю применим.

```bsl
"ВЫБРАТЬ
|    Номенклатура.Ссылка КАК Ссылка
|ИЗ
|    Справочник.Номенклатура КАК Номенклатура
|ГДЕ
|    Номенклатура.Родитель В (&Группы)"
```

законная форма добавлена 2026-09-21

## Как чинить

Разбей запрос на несколько, объединенных ОБЪЕДИНИТЬ ВСЕ: каждый использует индекс по своему полю.
