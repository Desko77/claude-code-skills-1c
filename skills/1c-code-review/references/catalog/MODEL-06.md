# MODEL-06. Функции-помощники по одному полю ответа

## Идентификатор и группа

Идентификатор: `MODEL-06`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Minor

## Триггер

Набор функций-помощников, каждая читает из одного и того же ответа одно поле и приводит его к нужному типу

## Почему дефект

Разбор ответа размазан по нескольким функциям: изменение формата ответа требует правки каждой, одинаковые проверки отсутствия полей повторяются. Один метод разбора дает одну точку проверки структуры ответа.

## Законная форма

Ответ разбирается одним методом, возвращающим типизированную структуру; точки вызова читают готовые поля.

```bsl
Функция РазобратьОтвет(Ответ)
    Данные = Новый Структура;
    Данные.Вставить("Код", Ответ.Code);
    Данные.Вставить("Номер", Ответ.Number);
    Данные.Вставить("Дата", Ответ.Date);
    Возврат Данные;
КонецФункции
```

## Как чинить

Объедини функции-помощники в один метод разбора ответа: он проверяет структуру один раз и возвращает типизированную структуру или объект. Точки вызова работают с готовыми полями.
