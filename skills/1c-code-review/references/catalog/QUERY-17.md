# QUERY-17. Псевдоним источника затеняет имя колонки

## Идентификатор и группа

Идентификатор: `QUERY-17`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Псевдоним источника в запросе совпадает с именем колонки или табличной части, видимыми в том же запросе

## Почему дефект

Одно имя указывает на две вещи: колонку и таблицу. Читатель и последующие секции запроса получают не то поле, на которое указывает имя; при соединении табличной части с владельцем псевдоним, совпадающий с именем табличной части, подменяет обращение к ней. Данные в результате неверные, ошибки нет.

## Законная форма

Псевдоним источника отличается от имен колонок и табличных частей, видимых в запросе.

```bsl
ВЫБРАТЬ
    Спр.Ссылка КАК Ссылка,
    Спр.Родитель КАК Родитель
ИЗ
    Справочник.Номенклатура КАК Спр
        ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Папки КАК РодительГруппы
        ПО Спр.Родитель = РодительГруппы.Ссылка
```

## Как чинить

Переименуй псевдоним источника так, чтобы он не совпадал ни с одной колонкой и табличной частью запроса (суффикс роли: РодительГруппы, ТоварыСтроки). Проверь все секции, где встречается прежнее имя.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Совпадение псевдонима источника с именем колонки требует состава полей запроса; запрос при этом выполняется.
