# CLIENT-02. НаСервере вместо НаСервереБезКонтекста

## Идентификатор и группа

Идентификатор: `CLIENT-02`
Группа: `CLIENT` (клиент-серверное взаимодействие)
Псевдоним: п.7 (anti_patterns.md)

## Важность

Major

## Триггер

Серверная функция модуля формы с директивой НаСервере не обращается к реквизитам формы

## Почему дефект

НаСервере передает контекст формы на сервер и обратно: если функция не читает и не меняет реквизиты формы, передача контекста выполняется вхолостую.

## Законная форма

НаСервере у функции, которая читает и меняет реквизиты формы: контекст ей нужен.

```bsl
&НаСервере
Процедура ЗаполнитьТаблицуНаСервере()
    Объект.Товары.Очистить();
    ЗаполнитьСтроки(Объект.Товары);
КонецПроцедуры
```

## Как чинить

Переведи функцию на НаСервереБезКонтекста: нужные данные передаются параметрами, результат возвращается значением.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: ServerSideExportFormMethod ловит только экспортные методы формы, а триггер шире: функция без обращения к реквизитам формы может быть не экспортной; признак требует анализа тела метода.
