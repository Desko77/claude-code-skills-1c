# EXT-01. Прямая правка заимствованного модуля расширения

## Идентификатор и группа

Идентификатор: `EXT-01`
Группа: `EXT` (расширения конфигурации)

## Важность

Major

## Триггер

Тело заимствованной процедуры расширения изменено напрямую, без перехватчика

## Почему дефект

Модуль заимствованного объекта управляется перехватчиками; прямая правка выпадает из модели расширения и теряется при сравнении с новой версией основной конфигурации.

## Законная форма

Дополнительный код подключается перехватчиком &Перед или &После: тело оригинала не трогается.

```bsl
&НаСервере
&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи()
    // Дополнительный код до оригинального ПриЗаписи
КонецПроцедуры
```

## Как чинить

Замени прямую правку перехватчиком: &Перед или &После для дополнения, &ИзменениеИКонтроль с ПродолжитьВызов() для изменения логики.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Прямая правка заимствованной процедуры распознается сравнением с основной конфигурацией; инструмент сравнения в словаре детекторов отсутствует.
