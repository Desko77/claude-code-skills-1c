# QUERY-05. Наименование ссылки вместо ПРЕДСТАВЛЕНИЕ

## Идентификатор и группа

Идентификатор: `QUERY-05`
Группа: `QUERY` (язык запросов)

## Важность

Minor

## Триггер

Из ссылки в списке полей читается Наименование только ради отображения

## Почему дефект

Ради текста представления запрос соединяется с таблицей справочника; ПРЕДСТАВЛЕНИЕ() отдает тот же текст без соединения в тексте запроса.

## Законная форма

Наименование читается как данные: по нему ищут, его сравнивают или выгружают в документ - нужен сам реквизит, а не представление.

```bsl
"ВЫБРАТЬ
|    Контрагенты.Наименование КАК Наименование
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    Контрагенты.Наименование ПОДОБНО &Шаблон"
```

законная форма добавлена 2026-09-21

## Как чинить

Замени чтение Наименование на ПРЕДСТАВЛЕНИЕ(Поле) КАК ПолеПредставление, когда нужен только текст для отображения.
