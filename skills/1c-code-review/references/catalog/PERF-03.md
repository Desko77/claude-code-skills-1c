# PERF-03. Повторный дорогой вызов с теми же аргументами

## Идентификатор и группа

Идентификатор: `PERF-03`
Группа: `PERF` (производительность)
Псевдоним: п.9 (anti_patterns.md)

## Важность

Minor

## Триггер

В цикле вызывается функция с одинаковыми аргументами, результат не сохраняется

## Почему дефект

Одинаковое вычисление повторяется на каждой итерации: время растет на число повторов, а не на число уникальных значений аргументов.

## Законная форма

Вызов с аргументами, меняющимися от строки к строке: каждая итерация дает новое значение, кеш был бы пустым.

```bsl
Для Каждого Строка Из Строки Цикл
    Курс = ПолучитьКурсВалюты(Строка.Валюта, Строка.Дата);
КонецЦикла;
```

законная форма добавлена 2026-09-21

## Как чинить

Кешируй результат в Соответствие: ключ строится из аргументов (валюта и дата сведены в строку), промах кеша вызывает функцию один раз на уникальный ключ.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Повторный вызов функции с одинаковыми аргументами требует знания стоимости функции; диагностики такого признака нет.
