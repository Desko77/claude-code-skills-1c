# QUERY-10. Условия не по индексу

## Идентификатор и группа

Идентификатор: `QUERY-10`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Условия ГДЕ заданы по полям, пропускающим первые поля индекса таблицы

## Почему дефект

Индекс работает, когда условия идут по его полям с начала, подряд и без пропусков: пропуск первого поля или разрыв в середине отключает индекс целиком.

## Законная форма

Условия по всем ведущим полям индекса (Организация, Контрагент при индексе (Организация, Контрагент, Дата)).

```bsl
// Индекс: (Организация, Контрагент, Дата)
"ВЫБРАТЬ
|    Расчеты.Ссылка КАК Ссылка
|ИЗ
|    Документ.Реализация КАК Расчеты
|ГДЕ
|    Расчеты.Организация = &Организация
|    И Расчеты.Контрагент = &Контрагент"
```

## Как чинить

Строй условия по ведущим полям индекса; для временных таблиц в соединениях добавляй ИНДЕКСИРОВАТЬ ПО, для часто фильтруемых реквизитов включай индексирование в свойствах объекта.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Несоответствие условий индексам требует состава индексов таблицы; инструменты словаря с метаданными так не работают.
