# QUERY-12. Поля внешнего соединения без ЕСТЬNULL

## Идентификатор и группа

Идентификатор: `QUERY-12`
Группа: `QUERY` (язык запросов)

## Важность

Minor

## Триггер

Из полей правой таблицы ЛЕВОГО СОЕДИНЕНИЯ значения читаются без ЕСТЬNULL

## Почему дефект

Для строк без совпадения поле равно NULL: арифметика с NULL дает NULL, сравнения отсекают строки, итоги искажаются.

## Законная форма

Поля внешнего соединения используются только для вывода и группировки, без арифметики и сравнений: NULL в выводе безопасен.

```bsl
"ВЫБРАТЬ
|    Заказы.Ссылка КАК Заказ,
|    Итоги.Сумма КАК СуммаОплат
|ИЗ
|    Документ.Заказ КАК Заказы
|        ЛЕВОЕ СОЕДИНЕНИЕ ВТИтогиОплат КАК Итоги
|        ПО Заказы.Ссылка = Итоги.Заказ"
```

законная форма добавлена 2026-09-21

## Как чинить

Оберни используемые в вычислениях поля внешнего соединения в ЕСТЬNULL(Поле, 0).
