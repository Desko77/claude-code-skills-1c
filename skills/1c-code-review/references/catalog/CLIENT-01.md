# CLIENT-01. Серия клиент-серверных вызовов одной операции

## Идентификатор и группа

Идентификатор: `CLIENT-01`
Группа: `CLIENT` (клиент-серверное взаимодействие)
Псевдоним: п.6 (anti_patterns.md)

## Важность

Major

## Триггер

Из клиентской процедуры подряд вызывается несколько серверных функций для одной операции

## Почему дефект

Каждый вызов - сетевой переход и сериализация контекста: три вызова одной операции утраивают задержку и гоняют одни и те же данные повторно.

## Законная форма

Несколько серверных вызовов в одной клиентской процедуре, где каждый завершает самостоятельный шаг и следующий невозможен без результата предыдущего: запись, затем печать по ссылке на записанный документ.

```bsl
&НаКлиенте
Процедура ЗаписатьИПечать(Команда)
    Ссылка = ЗаписатьДокументНаСервере();
    ПечатьДокумента(Ссылка);
КонецПроцедуры
```

законная форма добавлена 2026-09-21

## Как чинить

Собери все данные одной операции в один серверный вызов НаСервереБезКонтекста, возвращающий структуру с результатами всех шагов.
