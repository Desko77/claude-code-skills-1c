# TXN-08. Блокировка по широкому отбору

## Идентификатор и группа

Идентификатор: `TXN-08`
Группа: `TXN` (транзакции и блокировки)

## Важность

Minor

## Триггер

Блокировка устанавливается без значений отбора или по всей таблице

## Почему дефект

Блокировка таблицы целиком превращает параллельную работу сеансов в последовательную: все операции по таблице выстраиваются в очередь.

## Законная форма

Блокировка всей таблицы, когда операция по определению затрагивает все записи: полный пересчет итогов регистра.

```bsl
// Полный пересчет затрагивает все записи регистра, отбор не сузить.
Блокировка = Новый БлокировкаДанных;
Блокировка.Добавить("РегистрНакопления.ТоварыНаСкладах");
Блокировка.Заблокировать();
```

законная форма добавлена 2026-09-21

## Как чинить

Задавай отбор как можно уже: по конкретным значениям измерений операции (склад, организация, документ), а не по таблице.
