# MODEL-05. Коллекция без Знач в читающем методе

## Идентификатор и группа

Идентификатор: `MODEL-05`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Minor

## Триггер

Параметр-коллекция (структура, массив, таблица значений) объявлен без Знач, хотя метод ее не изменяет

## Почему дефект

Без Знач метод получает ссылку на коллекцию вызывающего: случайное изменение внутри метода меняет данные в точке вызова, и намерение только читать нигде не зафиксировано. Для серверного метода, вызываемого с клиента, копирование коллекции также выполняется без необходимости.

## Законная форма

Коллекция, которую метод только читает, объявлена со Знач: изменение внутри метода не затронет данные вызывающего кода.

```bsl
Функция СуммаСтрок(Знач Строки)
    Сумма = 0;
    Для Каждого Строка Из Строки Цикл
        Сумма = Сумма + Строка.Сумма;
    КонецЦикла;
    Возврат Сумма;
КонецФункции
```

## Как чинить

Добавь Знач к параметрам-коллекциям, которые метод не изменяет. Параметр без Знач оставь только там, где метод намеренно возвращает данные через коллекцию вызывающего, и опиши это в шапке метода.
