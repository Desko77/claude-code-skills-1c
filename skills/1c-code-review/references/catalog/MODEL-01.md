# MODEL-01. Глубокая вложенность условий

## Идентификатор и группа

Идентификатор: `MODEL-01`
Группа: `MODEL` (признаки кода модели)
Псевдоним: п.11 (anti_patterns.md)

## Важность

Minor

## Триггер

Более четырех уровней вложенности условий и циклов в одной процедуре

## Почему дефект

Каждый уровень умножает число путей выполнения, которые читатель держит в голове: правка такого кода порождает ошибки в пропущенных ветках.

## Законная форма

Вложенность, отражающая структуру данных (уровни дерева), а не логику условий: каждый уровень соответствует реальному уровню справочника.

```bsl
Для Каждого Группа Из ГруппыВерхнегоУровня Цикл
    Для Каждого Подгруппа Из Группа.Строки Цикл
        Для Каждого Номенклатура Из Подгруппа.Строки Цикл
            ОбработатьЭлемент(Номенклатура);
        КонецЦикла;
    КонецЦикла;
КонецЦикла;
```

законная форма добавлена 2026-09-21

## Как чинить

Ранний выход: негативные условия проверяются в начале, выход из процедуры через Возврат, из итерации цикла через Продолжить; основная логика остается на верхнем уровне.
