# PROC-01. Заявление о проверке без следа

## Идентификатор и группа

Идентификатор: `PROC-01`
Группа: `PROC` (дефекты процесса ответа)

## Важность

Major

## Триггер

В отчете заявлено выполнение проверки (проверено, работает, исправлено) без команды прогона и его результата

## Почему дефект

Заявление без следа не проверяется никем: при разборе инцидента подтвердить его нельзя, а сделанный на его основе вывод наследует недоказанность. Проверка, не оставившая следа, для следующего шага равна отсутствующей.

## Законная форма

Рядом с заявлением стоит проверяемый след: команда прогона и ее результат, номер теста, вывод инструмента.

```json
{
    "claim": "запрос проверен",
    "run": "validate_query",
    "result": "pass",
    "queryHash": "3f9a..."
}
```

## Как чинить

К заявлению о проверке прикладывай след: выполненную команду и ее результат. Проверка без проверяемого следа в отчете не заявляется - пишется прямо, что не проверено.
