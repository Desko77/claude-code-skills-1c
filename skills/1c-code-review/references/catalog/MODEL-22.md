# MODEL-22. Удаление элементов при обходе коллекции

## Идентификатор и группа

Идентификатор: `MODEL-22`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Внутри цикла Для Каждого по коллекции вызывается удаление элемента этой же коллекции: Строки.Удалить(Строка)

## Почему дефект

Итератор после удаления смещается: элементы, следующие за удаленным, пропускаются или обход повторяет уже сдвинутые строки. Часть пустых строк остается в коллекции, часть обрабатывается дважды; поведение зависит от размера коллекции и позиции удаления, поэтому ошибка не воспроизводится на малых примерах.

## Законная форма

Удаление по индексу в отдельном цикле с контролем индекса, сбор подлежащих удалению элементов с последующим удалением за пределами обхода.

```bsl
ПодлежатУдалению = Новый Массив;
Для Каждого Строка Из Строки Цикл
    Если Строка.Количество = 0 Тогда
        ПодлежатУдалению.Добавить(Строка);
    КонецЕсли;
КонецЦикла;
Для Каждого Строка Из ПодлежатУдалению Цикл
    Строки.Удалить(Строка);
КонецЦикла
```

## Как чинить

Замени прямой обход: собери удаляемые элементы в массив и удали их вторым проходом, либо обходи коллекцию по индексу от конца к началу с ручным управлением индексом.
