# QUERY-09. ОБЪЕДИНИТЬ без ВСЕ

## Идентификатор и группа

Идентификатор: `QUERY-09`
Группа: `QUERY` (язык запросов)

## Важность

Minor

## Триггер

Пакеты объединены через ОБЪЕДИНИТЬ без слова ВСЕ при отсутствии дубликатов

## Почему дефект

ОБЪЕДИНИТЬ выполняет дополнительную группировку всей выборки ради удаления дубликатов; без дубликатов эта работа выполняется вхолостую.

## Законная форма

ОБЪЕДИНИТЬ без ВСЕ, когда дубликаты ожидаемы и нужны именно различные строки: объединение двух списков с пересечением.

```bsl
"ВЫБРАТЬ
|    ОтветственныеСотрудники.Ссылка КАК Сотрудник
|ИЗ
|    Справочник.Сотрудники.Ответственные КАК ОтветственныеСотрудники
|ОБЪЕДИНИТЬ
|ВЫБРАТЬ
|    ПодписантыДокументов.Ссылка
|ИЗ
|    Справочник.Сотрудники.Подписанты КАК ПодписантыДокументов"
```

## Как чинить

Если дубликаты не ожидаются - пиши ОБЪЕДИНИТЬ ВСЕ: группировка для удаления дубликатов пропускается.
