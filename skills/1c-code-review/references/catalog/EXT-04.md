# EXT-04. Enum в Rights.xml роли расширения

## Идентификатор и группа

Идентификатор: `EXT-04`
Группа: `EXT` (расширения конфигурации)

## Важность

Major

## Триггер

В Rights.xml роли расширения есть блок прав вида Enum.ИмяПеречисления

## Почему дефект

Перечисления общедоступны, явные права избыточны; загрузка расширения LoadConfigFromFiles -Extension зависает без сообщения (платформа 8.3.27).

## Законная форма

Права роли расширения на собственные объекты расширения, без Enum-блоков.

```bsl
<object>
    <name>Catalog.Расш1_ДопСправочник</name>
    <right><name>Read</name><value>true</value></right>
    <right><name>View</name><value>true</value></right>
</object>
```

законная форма добавлена 2026-09-21

## Как чинить

Удали блоки Enum.* из Rights.xml; права задаются на объекты, требующие разграничения: справочники, документы, регистры.
