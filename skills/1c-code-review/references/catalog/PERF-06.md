# PERF-06. Поиск по наименованию или коду в теле механизма

## Идентификатор и группа

Идентификатор: `PERF-06`
Группа: `PERF` (производительность)

## Важность

Minor

## Триггер

НайтиПоНаименованию или НайтиПоКоду ищет элемент, от которого зависит работа механизма
Тот же класс - НайтиПоРеквизиту: поиск по неиндексированному полю вместо предопределенного элемента или константы

## Почему дефект

Поиск по наименованию сканирует справочник и зависит от данных, которые пользователь правит: переименованный элемент - механизм находит другой или не находит ничего, отказ проявляется не сразу. Зависимость механизма от справочных данных должна опираться на предопределенные элементы или ссылки.

## Законная форма

Элемент, от которого зависит код, - предопределенный: доступ по имени менеджера справочника, без поиска.

```bsl
Статья = Справочники.СтатьиЗатрат.ТранспортныеРасходы;
Склад = Справочники.Склады.ОсновнойСклад;
Документ.СтатьяЗатрат = Статья;
Документ.Склад = Склад;
```

## Как чинить

Замени поиск по наименованию или коду предопределенным элементом (доступ по имени менеджера) или передачей ссылки параметром. НайтиПоНаименованию допустим в интерактивном коде поиска пользователем, не в теле механизма.
