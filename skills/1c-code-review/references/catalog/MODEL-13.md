# MODEL-13. Параметр без умолчания при одном значении в вызовах

## Идентификатор и группа

Идентификатор: `MODEL-13`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Minor

## Триггер

Во всех точках вызова метод получает одно и то же значение параметра, а умолчания в сигнатуре нет

## Почему дефект

Значение дублируется в каждой точке вызова: смена режима требует правки всех вызовов, пропущенный вызов молча работает в неверном режиме. Сигнатура не показывает, что параметр почти всегда одинаков.

## Законная форма

Параметр объявлен со значением по умолчанию (Знач Формат = ...): точки вызова без особого режима не передают аргумент.

```bsl
Процедура СохранитьОтчет(Данные, Знач Формат = "MXL")
    Запись.УстановитьФормат(Формат);
КонецПроцедуры
```

## Как чинить

Добавь параметру значение по умолчанию (Знач <Имя> = <Значение>) и убери аргумент из точек вызова, передающих это же значение. Если особое значение одно и навсегда - убери параметр совсем.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Одинаковое значение параметра во всех вызовах требует обзора всех точек вызова; такой семантики в словаре нет.
