# PERF-05. Константа или предопределенный элемент внутри цикла

## Идентификатор и группа

Идентификатор: `PERF-05`
Группа: `PERF` (производительность)

## Важность

Minor

## Триггер

Внутри цикла читается константа или разыменовывается предопределенный элемент, хотя значение не зависит от итерации

## Почему дефект

Значение одинаково для всех итераций, а читается на каждой: Константы.Имя.Получить() обращается к базе на каждом проходе цикла. Вынос чтения за цикл убирает N-1 обращений.

## Законная форма

Значения, не зависящие от итерации, читаются до цикла в переменные.

```bsl
Валюта = Константы.ВалютаУчета.Получить();
Организация = Справочники.Организации.Основная;
Для Каждого Товар Из Товары Цикл
    Товар.Валюта = Валюта;
    Товар.Организация = Организация;
КонецЦикла;
```

## Как чинить

Вынеси чтение константы и разыменование предопределенного элемента за цикл в переменные; в теле цикла используй переменные.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:PERF-05 | static |

Обоснование чтения: Чтение константы или предопределенного элемента в цикле не выделяется диагностиками EDT; текстовый признак закрывается lint.
