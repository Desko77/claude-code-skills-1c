# MODEL-07. Несуществующий метод Получить у табличного документа

## Идентификатор и группа

Идентификатор: `MODEL-07`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Ячейка табличного документа читается методом Получить(), которого у типа ТабличныйДокумент нет

## Почему дефект

У типа ТабличныйДокумент нет метода Получить. Синтаксический контроль сообщает о вызове несуществующего метода, только когда тип переменной известен; при нетипизированном параметре, как здесь, контроль молчит, и обращение дает ошибку "Метод объекта не обнаружен" при выполнении.

## Законная форма

Ячейка читается через Область(Строка, Колонка, Строка, Колонка) - область одной ячейки, значение - ее свойство Текст.

```bsl
Ячейка = Таблица.Область(Строка, Колонка, Строка, Колонка);
Значение = Ячейка.Текст;
```

## Как чинить

Замени Получить(Строка, Колонка) на Область(Строка, Колонка, Строка, Колонка); значение ячейки - свойство Текст области. Существование метода типа проверяй по справочнику платформы, а не по аналогии с массивом: синтаксический контроль сообщает о несуществующем методе только при известном типе, нетипизированный параметр проверяется лишь выполнением.
