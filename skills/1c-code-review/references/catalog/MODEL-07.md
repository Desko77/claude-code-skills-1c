# MODEL-07. Несуществующий метод Получить у табличного документа

## Идентификатор и группа

Идентификатор: `MODEL-07`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Ячейка табличного документа читается методом Получить(), которого у типа ТабличныйДокумент нет

## Почему дефект

У типа ТабличныйДокумент нет метода Получить: модуль не проходит синтаксический контроль, а при отложенной проверке обращение дает ошибку "Метод объекта не обнаружен" в работе.

## Законная форма

Ячейка читается через Область(Строка, Колонка, Строка, Колонка) - область одной ячейки, значение - ее свойство Текст.

```bsl
Ячейка = Таблица.Область(Строка, Колонка, Строка, Колонка);
Значение = Ячейка.Текст;
```

## Как чинить

Замени Получить(Строка, Колонка) на Область(Строка, Колонка, Строка, Колонка); значение ячейки - свойство Текст области. Проверяй существование метода типа по синтаксическому контролю или справочнику платформы, не по аналогии с массивом.
