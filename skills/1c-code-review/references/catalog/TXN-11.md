# TXN-11. Запись и проведение в одной явной транзакции

## Идентификатор и группа

Идентификатор: `TXN-11`
Группа: `TXN` (транзакции и блокировки)

## Важность

Major

## Триггер

Запись документа и его проведение объединены в одну явную транзакцию

## Почему дефект

Платформа сама записывает и проводит документ атомарно. Явная транзакция вокруг обеих операций держит блокировки дольше необходимого, а при отказе проведения откатывает и запись: пользователь теряет введенные данные, которые без своей транзакции сохранились бы черновиком.

## Законная форма

Запись с проведением выполняется одним вызовом в транзакции платформы, без явной транзакции.

```bsl
Процедура ПровестиДокумент(Документ)
    Документ.Записать(РежимЗаписиДокумента.Проведение);
КонецПроцедуры
```

## Как чинить

Убери явную транзакцию и выполни Записать(РежимЗаписиДокумента.Проведение) - платформа делает запись и проведение атомарно. Явная транзакция нужна только для нескольких разнородных объектов сразу.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | ask_1c_ai | llm |
| EDT | чтение | read |
| Конфигуратор | bsl_validate:TXN-11 | static |

Обоснование чтения: Запись с проведением внутри явной транзакции диагностиками не выделяется; текстовый признак закрывается lint.
