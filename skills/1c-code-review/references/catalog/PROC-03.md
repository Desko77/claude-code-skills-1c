# PROC-03. Правка молча убирает проверки редких случаев

## Идентификатор и группа

Идентификатор: `PROC-03`
Группа: `PROC` (дефекты процесса ответа)

## Важность

Major

## Триггер

Правка удаляет из исходного кода проверки редких и граничных случаев, а добавленные операции записи выполняются без чтения результата

## Почему дефект

Удаленные проверки молча расширяют множество входов, на которых код падает или портит данные: читатель diff видит уточнение, а охват изменился. Запись без проверки результата скрывает отказ на тех же редких входах.

## Законная форма

Правка сохраняет проверки исходного кода; операции записи проверяют результат; удаление проверки - отдельная правка с обоснованием.

```json
{
    "claim": "правка не меняет охват",
    "diff": "module.bsl",
    "removedChecks": 0,
    "unrecordedWrites": 0
}
```

## Как чинить

При правке метода перенеси существующие проверки редких случаев в новый код; после каждой записи читай результат (ссылку, число записанных строк) или проверяй отказ. Удаляй проверку только отдельной правкой с описанием, почему случай больше не возможен.

## Детекторы

| Среда | Детектор | Уровень |
|-------|----------|---------|
| EDT | чтение | read |
| Конфигуратор | чтение | read |

Обоснование чтения: Удаление проверок граничных случаев и запись без чтения результата - семантика изменения; автоматического детектора нет.
