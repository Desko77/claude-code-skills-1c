# SEC-03. Секрет в коде явным значением

## Идентификатор и группа

Идентификатор: `SEC-03`
Группа: `SEC` (безопасность)

## Важность

Critical

## Триггер

В коде встречается пароль, токен или ключ строковым литералом

## Почему дефект

Секрет виден каждому, кто читает код, выгрузку или историю хранилища; замена секрета требует правки и перевыпуска кода.

## Законная форма

Секрет приходит параметром сеанса, установленным администратором: в коде литерала нет.

```bsl
Токен = ПараметрыСеанса.ТокенИнтеграции;
Ответ = ОтправитьЗапрос(АдресСервиса, Токен, Тело);
```

законная форма добавлена 2026-09-21

## Как чинить

Убирай секреты из кода: безопасное хранилище, параметры сеанса, настройки интеграции; в коде остается только обращение по имени.
