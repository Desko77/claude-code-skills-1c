# PERF-01. Запрос в цикле

## Идентификатор и группа

Идентификатор: `PERF-01`
Группа: `PERF` (производительность)
Псевдоним: п.1 (anti_patterns.md)

## Важность

Critical

## Триггер

В цикле создается Новый Запрос или выполняется Выполнить() на каждой итерации

## Почему дефект

N обращений к базе вместо одного: время растет линейно по числу итераций, каждая итерация платит за разбор текста, построение плана и обмен с СУБД.

## Законная форма

Тот же отбор одним обращением: список ссылок передается параметром В (&СписокСсылок), цикла с запросом нет.

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|    Товары.Ссылка КАК Ссылка
|ИЗ
|    Документ.Поступление.Товары КАК Товары
|ГДЕ
|    Товары.Ссылка В (&СписокСсылок)";
Запрос.УстановитьПараметр("СписокСсылок", Строки.ВыгрузитьКолонку("Ссылка"));
РезультатЗапроса = Запрос.Выполнить();
```

## Как чинить

Вынеси запрос из цикла: собери набор значений (ВыгрузитьКолонку, Массив), передай его параметром В (&Список), сверь строки результата по Соответствию. Набор однотипных запросов объединяется пакетом.
