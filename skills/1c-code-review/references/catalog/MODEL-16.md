# MODEL-16. Вызов метода, удаленного этой же правкой

## Идентификатор и группа

Идентификатор: `MODEL-16`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Critical

## Триггер

Правка удаляет метод модуля, а вызовы его из других процедур того же модуля остаются

## Почему дефект

Модуль с вызовом несуществующего метода не проходит синтаксический контроль; если проверка не выполнена, обращение дает ошибку "Метод объекта не обнаружен" при первом выполнении затронутой процедуры.

## Законная форма

Правка удаляет метод вместе со всеми вызовами или оставляет метод на месте; каждый вызов в измененном модуле имеет объявление.

```bsl
Процедура НапечататьШапку(Документ)
    Текст = Новый Массив;
    Текст.Добавить(НомерДокументаСтрокой(Документ));
    ВывестиТекст(Текст);
КонецПроцедуры

Функция НомерДокументаСтрокой(Документ)
    Возврат "N " + Документ.Номер;
КонецФункции
```

## Как чинить

Перед удалением метода найди все его вызовы (поиск по имени в модуле и проекте) и убери их той же правкой. После правки выполни синтаксический контроль модуля - у каждого вызова есть объявление.
