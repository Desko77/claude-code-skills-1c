# SEC-02. Нет проверки прав перед операцией с данными

## Идентификатор и группа

Идентификатор: `SEC-02`
Группа: `SEC` (безопасность)

## Важность

Critical

## Триггер

Код читает или изменяет данные с ограничением RLS без проверки ПравоДоступа() или РольДоступна()

## Почему дефект

Обход ограничения уровня записей: пользователь получает доступ к данным или операции, которые ограничение отсекает; при включенном привилегированном режиме ограничение снимается незаметно для вызывающего кода.

## Законная форма

Штатная запись объекта через объектные методы платформы: платформа сама применяет права и RLS текущего сеанса, явная проверка дублировала бы ее.

```bsl
Если Не Объект.Ссылка.Пустая() Тогда
    Объект.Записать();
КонецЕсли;
```

законная форма добавлена 2026-09-21

## Как чинить

Добавь проверку прав перед нестандартной операцией: ПравоДоступа("Изменение", Метаданные.Справочники.Клиенты) или РольДоступна("Администратор"); привилегированный режим - минимально и с обязательным выключением.
