# QUERY-04. Поле составного типа без ВЫРАЗИТЬ

## Идентификатор и группа

Идентификатор: `QUERY-04`
Группа: `QUERY` (язык запросов)

## Важность

Major

## Триггер

Через точку читается поле составного типа без ВЫРАЗИТЬ

## Почему дефект

Обращение к полю составного типа строит соединения со всеми возможными типами: запрос платит за левое соединение к каждой таблице-кандидату.

## Законная форма

Чтение самого ссылочного поля составного типа без обращения к его полям: соединений нет, значение ссылки читается из своей таблицы.

```bsl
"ВЫБРАТЬ
|    ТоварыНаСкладах.Регистратор КАК Документ
|ИЗ
|    РегистрНакопления.ТоварыНаСкладах КАК ТоварыНаСкладах"
```

## Как чинить

Укажи конкретный тип через ВЫРАЗИТЬ(Поле КАК Тип.Имя); для нескольких типов - ВЫБОР КОГДА Поле ССЫЛКА Тип.Имя ТОГДА ВЫРАЗИТЬ(...).
