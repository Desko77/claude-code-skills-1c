# MODEL-20. Обработчик записи без проверки ОбменДанными.Загрузка

## Идентификатор и группа

Идентификатор: `MODEL-20`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Major

## Триггер

Обработчик ПриЗаписи, ПередЗаписью или набора записей выполняет побочные действия - заполнение реквизитов, движения, сообщения, вызовы внешних сервисов - без выхода при ОбменДанными.Загрузка

## Почему дефект

При загрузке данных обменом обработчики записи выполняются платформой: побочные эффекты срабатывают на принимающей стороне и портят загружаемые данные - заполняют реквизиты заново, создают движения поверх присланных, отправляют уведомления по каждой принятой записи. Обмен зацикливается: сообщение обратно порождает встречное.

## Законная форма

Обработчик не имеет побочных эффектов: контроль заполнения, работающий и при загрузке; либо валидация, сознательно выполняемая на обеих сторонах обмена.

```bsl
Процедура ПриЗаписи(Отказ)
    Если Не ОбменДанными.Загрузка Тогда
        ЗаполнитьНомерПоПравилам();
    КонецЕсли;
    ПроверитьЗаполнениеТабличнойЧасти(Отказ);
КонецПроцедуры
```

## Как чинить

В начале обработчика с побочными эффектами добавь выход: Если ОбменДанными.Загрузка Тогда Возврат; КонецЕсли. Оставь вне проверки только контроль данных, обязательный на обеих сторонах обмена.
