# MODEL-12. Повторный вызов функции ради одного поля результата

## Идентификатор и группа

Идентификатор: `MODEL-12`
Группа: `MODEL` (признаки кода, написанного моделью)

## Важность

Minor

## Триггер

Результат вызова своей функции читается через точку в нескольких местах метода вместо сохранения в переменную

## Почему дефект

Каждое обращение через точку - повторный вызов функции с той же работой внутри: разбор ответа, запрос, вычисление выполняются заново. В условиях и циклах число вызовов умножается.

## Законная форма

Функция вызывается один раз, результат сохраняется в переменную; поля читаются из переменной.

```bsl
Данные = ПолучитьДанныеОтвета(Ответ);
Если Данные.Код = 0 Тогда
    ОтправитьУведомление(Данные.Номер);
КонецЕсли;
```

## Как чинить

Сохрани результат вызова в переменную и читай поля из нее. Если вызов дорогой - вынеси его из условия и цикла, чтобы он выполнялся один раз.
