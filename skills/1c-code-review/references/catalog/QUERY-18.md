# QUERY-18. ПЕРВЫЕ N без УПОРЯДОЧИТЬ ПО

## Идентификатор и группа

Идентификатор: `QUERY-18`
Группа: `QUERY` (язык запросов)

## Важность

Minor

## Триггер

В запросе стоит ПЕРВЫЕ N, а секции УПОРЯДОЧИТЬ ПО нет
Сюда же - ПЕРВЫЕ с АВТОУПОРЯДОЧИВАНИЕМ: состав полей порядка не определен разработчиком

## Почему дефект

Без упорядочивания состав первых N строк не определен: повторный запуск возвращает другие строки, отчеты и тесты недетерминированы. ПЕРВЫЕ 1 без порядка возвращает произвольную строку - той же природы дефект.

## Законная форма

ПЕРВЫЕ N сопровождается УПОРЯДОЧИТЬ ПО однозначному критерию. ПЕРВЫЕ 1 - либо упорядочиванием, либо условием, задающим ровно одну строку.

```bsl
ВЫБРАТЬ ПЕРВЫЕ 10
    Спр.Ссылка КАК Ссылка,
    Спр.Код КАК Код
ИЗ
    Справочник.Номенклатура КАК Спр
УПОРЯДОЧИТЬ ПО
    Спр.Код
```

## Как чинить

Добавь УПОРЯДОЧИТЬ ПО по критерию, который определяет, какие строки должны попасть в первые N. Критерий без индекса замедлит запрос - проверь план по правилам QUERY-10.
