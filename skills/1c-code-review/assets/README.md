# Ассеты скила 1c-code-review

## bsl-ls-gate.json

Гейтовый конфиг bsl-language-server в формате `.bsl-language-server.json`. Включены все
диагностики, на которые ссылаются карточки каталога дефектов (детекторы вида
`code_review:<КодДиагностики>`); важность каждой диагностики переопределена важностью
карточки (Critical -> CRITICAL, Major -> MAJOR, Minor -> MINOR). Остальные диагностики
работают по умолчанию анализатора: конфиг не отключает ничего. Состав сверяется с
карточками гардом `tests/skills/check-catalog.mjs` в обе стороны; правится вместе с
матрицей детекторов карточек.

Конфиг отделен от проектного `.bsl-language-server.json`: гейтовый задает важность по
каталогу, проектный - настройки команды проекта.

Как передается анализатору:

- после выхода версии плагина AI-EDT с доводом `configurationPath` - вызовом
  `code_review configurationPath=<путь к bsl-ls-gate.json>`;
- до нее - копированием содержимого в `.bsl-language-server.json` корня воркспейса; след
  проверок в этом режиме помечает уровень доказательности `project-config`
  (конфиг не гейтовый, возможны локальные отличия).

Отключение диагностики в этом конфиге - только по замеру доли ложных срабатываний
(руками классифицируется выборка находок на реальном воркспейсе); решение и числа
фиксируются в `references/false-positives-*.md` с версией анализатора и конфига.
