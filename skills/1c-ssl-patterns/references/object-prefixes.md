# Префиксация объектов

Механизм БСП, подставляющий префикс в номер документа или код справочника при
записи: префикс информационной базы и префикс организации. Нужен, когда одни и те
же объекты создаются в нескольких базах или от нескольких организаций и номера не
должны сталкиваться.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ПрефиксацияОбъектовКлиентСервер` | программный интерфейс: разбор и сборка номера | сервер, тонкий и толстый клиент, внешнее соединение |
| `ПрефиксацияОбъектовПереопределяемый` | точка расширения: свои правила формирования префикса | сервер, толстый клиент, внешнее соединение |
| `ПрефиксацияОбъектовКлиентСерверПереопределяемый` | точка расширения: свое правило номера на печать | сервер, тонкий и толстый клиент, внешнее соединение |
| `ПрефиксацияОбъектовСобытия` | обработчики подписок на события, подставляющие префикс при записи | сервер, толстый клиент, внешнее соединение |
| `ПрефиксацияОбъектовСлужебный` | внутренняя реализация библиотеки | - |
| `ПрефиксацияОбъектовПовтИсп` | кэш повторного использования, служебный | - |

**Модуля `ПрефиксацияОбъектов` без суффикса не существует.** Разбор номера лежит в
`ПрефиксацияОбъектовКлиентСервер`, подстановка префикса при записи - в
`ПрефиксацияОбъектовСобытия`, а точки расширения - в двух модулях с суффиксом
`Переопределяемый`.

Модуль `ПрефиксацияОбъектовСобытия` устроен иначе, чем прочие: это не интерфейс
для вызова, а набор обработчиков, которые подписки на события библиотеки вызывают
сами. Прикладной код туда не обращается.

## Сценарии

### 1. Показать номер пользователю без префиксов

**Задача:** в печатной форме или в отчете вывести номер документа так, как его
называет человек, без служебных префиксов базы и организации.

**Функции:**

`ПрефиксацияОбъектовКлиентСервер.НомерНаПечать(Знач НомерОбъекта, УдалитьПрефиксИнформационнойБазы = Ложь, УдалитьПользовательскийПрефикс = Ложь) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Доступна и на клиенте, и на сервере.

**Параметры:**

- `НомерОбъекта` - `Строка`, номер или код как он лежит в базе.
- `УдалитьПрефиксИнформационнойБазы` - `Булево`, убрать префикс базы.
- `УдалитьПользовательскийПрефикс` - `Булево`, убрать префикс, заданный
  пользователем.

**Пример:**

```bsl
&НаКлиенте
Функция НомерДляЗаголовка(Знач Номер)

    Возврат ПрефиксацияОбъектовКлиентСервер.НомерНаПечать(Номер, Истина, Истина);

КонецФункции
```

**Нюансы и антипаттерны:**

- Не резать номер строковыми функциями по фиксированной длине: длина префикса
  зависит от настроек базы и организации и меняется между внедрениями.
- Функция доступна на клиенте, поэтому серверный вызов ради нее не нужен.

### 2. Разобрать номер на части

**Задача:** получить из номера отдельно пользовательский префикс либо очистить
номер от лидирующих нулей перед сравнением.

**Функции:**

`ПрефиксацияОбъектовКлиентСервер.ПользовательскийПрефикс(Знач НомерОбъекта) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`.

`ПрефиксацияОбъектовКлиентСервер.УдалитьЛидирующиеНулиИзНомераОбъекта(Знач НомерОбъекта) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`.

`ПрефиксацияОбъектовКлиентСервер.УдалитьПрефиксыИзНомераОбъекта(Знач НомерОбъекта, УдалитьПрефиксОрганизации = Ложь, УдалитьПрефиксИнформационнойБазы = Ложь) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`.

**Пример:**

```bsl
&НаСервере
Функция НомераСовпадают(Знач Первый, Знач Второй)

    Первый = ПрефиксацияОбъектовКлиентСервер.УдалитьЛидирующиеНулиИзНомераОбъекта(
        ПрефиксацияОбъектовКлиентСервер.УдалитьПрефиксыИзНомераОбъекта(Первый, Истина, Истина));
    Второй = ПрефиксацияОбъектовКлиентСервер.УдалитьЛидирующиеНулиИзНомераОбъекта(
        ПрефиксацияОбъектовКлиентСервер.УдалитьПрефиксыИзНомераОбъекта(Второй, Истина, Истина));

    Возврат Первый = Второй;

КонецФункции
```

**Нюансы и антипаттерны:**

- Сравнивать номера из разных баз без снятия префиксов бессмысленно: у одного и
  того же документа они разные.
- `УдалитьПрефиксыИзНомераОбъекта` по умолчанию не убирает ни один из префиксов -
  оба параметра нужно передавать явно.

### 3. Задать свое правило формирования префикса

**Задача:** префикс организации берется не из типового реквизита, а из своего.

**Функции:**

`ПрефиксацияОбъектовПереопределяемый.ПолучитьПрефиксообразующиеРеквизиты(Объекты) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК: библиотека вызывает его сама.

`ПрефиксацияОбъектовПереопределяемый.ПриИзмененииНомера(Объект, Знач Номер, БазовыйНомер, СтандартнаяОбработка) Экспорт`
и `ПриИзмененииКода(Объект, Знач Код, БазовыйКод, СтандартнаяОбработка) Экспорт`
- процедуры, тот же регион и та же роль хука.

**Параметры:**

- `Объекты` - `Соответствие`, куда добавляется объект метаданных и имя реквизита,
  из которого берется префиксообразующее значение.
- `СтандартнаяОбработка` - `Булево`; сброс в `Ложь` отключает типовое поведение.

**Пример:**

```bsl
// Модуль ПрефиксацияОбъектовПереопределяемый, тело хука.
Процедура ПолучитьПрефиксообразующиеРеквизиты(Объекты) Экспорт

    Объекты.Вставить(Метаданные.Документы.РасходТовара, "Подразделение");

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не вызывать `ПрефиксацияОбъектовПереопределяемый.ПолучитьПрефиксообразующиеРеквизиты(...)`
  из прикладного кода: это хук, его реализуют.
- Реквизит, названный в хуке, должен быть у объекта на момент записи. Пустое
  значение даст номер без префикса организации, а не ошибку.

### 4. Подставить префикс своему объекту

**Задача:** новый документ конфигурации должен получать префикс так же, как
типовые.

**Механизм:** объект включается в подписки на события библиотеки. Обработчики
лежат в `ПрефиксацияОбъектовСобытия` и вызываются подписками, а не прикладным
кодом.

**Нюансы и антипаттерны:**

- Не вызывать обработчики `ПрефиксацияОбъектовСобытия` напрямую из модуля объекта:
  они рассчитаны на параметры подписки и порядок вызовов библиотеки.
- Подписка на событие настраивается в конфигурации; забытая подписка выглядит как
  работающий механизм с номерами без префикса.

## Различия версий

Состав модулей и их экспортные методы в 3.1.11 и 3.2.1 совпадают - сверено по
обеим поставкам.
