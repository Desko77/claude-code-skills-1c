# Пользователи

Механизм БСП, связывающий элемент справочника пользователей с учетной записью
информационной базы: текущий пользователь, полнота прав, внешние пользователи,
настройки пользователя.

Отвечает на вопрос КТО работает. На вопрос ЧТО ему разрешено видеть отвечает
управление доступом - другой механизм и другие модули.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `Пользователи` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `ПользователиКлиент` | программный интерфейс клиента, четыре функции | тонкий и толстый клиент |
| `ПользователиКлиентСервер` | общая часть | сервер и клиент |
| `ПользователиПереопределяемый` | точка расширения | сервер, толстый клиент, внешнее соединение |
| `ВнешниеПользователи`, `ВнешниеПользователиКлиент` | контрагенты и партнеры, работающие через отдельный вход | сервер / клиент |
| `ПользователиСлужебный` и еще восемь с тем же началом | внутренняя реализация библиотеки | - |

Клиентский модуль здесь публичный, но НЕБОЛЬШОЙ: в нем четыре функции о текущем
пользователе. Все остальное на сервере.

## Сценарии

### 1. Получить текущего пользователя

**Задача:** подставить автора в документ, отфильтровать список по пользователю,
показать имя в заголовке.

**Функции:**

`Пользователи.ТекущийПользователь() Экспорт` - функция, регион
`ПрограммныйИнтерфейс`. Сервер, толстый клиент, внешнее соединение. Возвращает
`СправочникСсылка.Пользователи`.

`ПользователиКлиент.ТекущийПользователь() Экспорт` - функция, тот же регион.
Тонкий и толстый клиент.

`Пользователи.АвторизованныйПользователь() Экспорт` и парная
`ПользователиКлиент.АвторизованныйПользователь() Экспорт` - функции, тот же
регион. Отличие от текущего: в сеансе внешнего пользователя возвращается объект
авторизации, а не элемент справочника пользователей.

**Пример:**

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)

    Заголовок = "Работает: " + Строка(ПользователиКлиент.ТекущийПользователь());

КонецПроцедуры

&НаСервере
Процедура ЗаполнитьАвтора(Объект)

    Объект.Автор = Пользователи.ТекущийПользователь();

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не звать серверный `Пользователи.ТекущийПользователь` из клиентского кода: у
  него контексты сервера, толстого клиента и внешнего соединения, на тонком
  клиенте его нет. Для клиента есть парный модуль с суффиксом `Клиент`.
- Не подменять его платформенным `ПользователиИнформационнойБазы.ТекущийПользователь`:
  тот возвращает учетную запись базы, а не элемент справочника, и связь между
  ними держит библиотека.
- **Свойства `Пользователи.СсылкаТекущегоПользователя` не существует.** Имя
  выглядит правдоподобно и встречается как выдумка; нужна функция
  `ТекущийПользователь`.

### 2. Проверить полноту прав

**Задача:** показать администратору то, что не показывают остальным.

**Функции:**

`Пользователи.ЭтоПолноправныйПользователь(Пользователь = Неопределено, ПроверятьПраваАдминистрированияСистемы = Ложь, СчитатьПолноправнымПользователемВФайловойИБ = Истина) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`ПользователиКлиент.ЭтоПолноправныйПользователь(ПроверятьПраваАдминистрированияСистемы = Ложь) Экспорт`
- функция, тот же регион. Клиент.

**Нюансы и антипаттерны:**

- Не проверять полноту прав перечислением ролей: набор ролей администратора
  различается между конфигурациями и внедрениями.
- Полнота прав это не разрешение на конкретные данные. Право на запись
  проверяется управлением доступом, а не этой функцией.

### 3. Понять, что сеанс внешнего пользователя

**Задача:** для контрагента, работающего через отдельный вход, показать другой
интерфейс.

**Функции:**

`Пользователи.ЭтоСеансВнешнегоПользователя() Экспорт` и парная
`ПользователиКлиент.ЭтоСеансВнешнегоПользователя() Экспорт` - функции, регион
`ПрограммныйИнтерфейс`.

`ВнешниеПользователи.ПолучитьОбъектАвторизацииВнешнегоПользователя(ВнешнийПользователь = Неопределено) Экспорт`
- функция, тот же регион. Сервер. Возвращает того контрагента или физическое
лицо, от имени которого работает внешний пользователь.

`ВнешниеПользователи.ИспользоватьВнешнихПользователей() Экспорт` - функция, тот
же регион: включен ли механизм вообще.

**Нюансы и антипаттерны:**

- Не обращаться к справочнику внешних пользователей, не проверив
  `ИспользоватьВнешнихПользователей`: при выключенном механизме справочник пуст, и
  ветка кода отработает молча и неверно.
- Текущий пользователь в сеансе внешнего пользователя это ВНЕШНИЙ пользователь.
  Объект авторизации берется отдельной функцией.

### 4. Найти пользователя по учетной записи базы

**Задача:** сопоставить учетную запись информационной базы с элементом
справочника.

**Функции:**

`Пользователи.НайтиПоИдентификатору(Знач ИдентификаторПользователяИБ) Экспорт`,
`Пользователи.НайтиПоИмени(Знач ИмяДляВхода) Экспорт`,
`Пользователи.НайтиПоСсылке(Пользователь) Экспорт` - функции, регион
`ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Не искать пользователя запросом по наименованию справочника: имя для входа и
  наименование это разные поля, и совпадают они не всегда.
- Пустой результат штатный: учетная запись могла быть удалена из базы, а элемент
  справочника остаться.

### 5. Выполнить свое действие при записи пользователя

**Задача:** при создании учетной записи завести связанные данные.

**Функции:**

`ПользователиПереопределяемый.ПриЗаписиПользователяИнформационнойБазы(Знач СтарыеСвойства, Знач НовыеСвойства) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК: библиотека вызывает его сама.

`ПользователиПереопределяемый.ПослеУдаленияПользователяИнформационнойБазы(Знач СтарыеСвойства) Экспорт`
- процедура, тот же регион и та же роль.

`ПользователиПереопределяемый.ПриОпределенииНазначенияРолей(НазначениеРолей) Экспорт`
- процедура, тот же регион: объявляет, какие роли считать служебными и какие
назначаются автоматически.

**Нюансы и антипаттерны:**

- Не вызывать процедуры `ПользователиПереопределяемый` из прикладного кода: их
  реализуют.
- В хуке приходят СВОЙСТВА, а не объект: старые и новые. Обращаться к справочнику
  за тем, что уже передано, незачем.
