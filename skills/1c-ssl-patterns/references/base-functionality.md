# Базовая функциональность

Базовые модули библиотеки, на которые опираются остальные механизмы: чтение реквизитов объектов без чтения самих объектов, сообщения
пользователю, работа с коллекциями, свойства сеанса и окружения, безопасный режим
выполнения. Самый большой механизм БСП - 211 методов только в серверном модуле.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ОбщегоНазначения` | базовый серверный модуль, 211 методов | сервер, толстый клиент, внешнее соединение |
| `ОбщегоНазначенияКлиентСервер` | то, что работает и на клиенте: коллекции, пути, отборы, адреса почты | сервер и клиент |
| `ОбщегоНазначенияКлиент` | клиентские свойства сеанса, оповещения, типовые диалоги | тонкий и толстый клиент |
| `ОбщегоНазначенияПереопределяемый` | точки расширения ядра, переименования объектов при обновлении | сервер, толстый клиент, внешнее соединение |
| `ОбщегоНазначенияВызовСервера` | вызов с клиента напрямую | сервер |

**Суффикс здесь особенно важен.** У одноименных методов разных модулей бывают
разные сигнатуры и разное поведение, и выбор модуля определяется тем, откуда идет
вызов, а не тем, что удобнее написать.

## Сценарии

### 1. Прочитать реквизит объекта, не читая объект

**Задача:** узнать одно поле документа в цикле или в отчете, не поднимая весь
объект из базы.

**Функции:**

`ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Ссылка, ИмяРеквизита, ВыбратьРазрешенные = Ложь) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Ссылка, Знач Реквизиты, ВыбратьРазрешенные = Ложь) Экспорт`
- функция, тот же регион: несколько реквизитов одного объекта.

`ОбщегоНазначения.ЗначенияРеквизитовОбъектов(Знач Ссылки, Знач Реквизиты, Знач ВыбратьРазрешенные = Ложь) Экспорт`
- функция, тот же регион: несколько реквизитов у СПИСКА объектов, одним запросом.

**Пример:**

```bsl
&НаСервере
Функция ОрганизацииДокументов(Знач Ссылки)

    Возврат ОбщегоНазначения.ЗначенияРеквизитовОбъектов(Ссылки, "Организация");

КонецФункции
```

**Нюансы и антипаттерны:**

- Не писать обращение вида точка-реквизит по ссылке в цикле: каждое обращение это отдельное чтение
  объекта из базы. На сотне строк разница уже заметна, на тысячах - критична.
- Для СПИСКА объектов брать `ЗначенияРеквизитовОбъектов` во множественном числе:
  одиночная функция в цикле сделает столько запросов, сколько объектов. Имена
  трех функций различаются одной буквой, и перепутать их легко.

### 2. Сообщить пользователю

**Задача:** показать сообщение, привязанное к полю формы, и прервать запись.

**Функции:**

`ОбщегоНазначения.СообщитьПользователю(Знач ТекстСообщенияПользователю, Знач КлючДанных = Неопределено, Знач Поле = "", Знач ПутьКДанным = "", Отказ = Ложь) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ОбщегоНазначенияКлиент.СообщитьПользователю(...)` - парная процедура для клиента,
тот же регион.

**Пример:**

```bsl
// Модуль объекта документа.
Процедура ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты)

    Если Не ЗначениеЗаполнено(Контрагент) Тогда
        ОбщегоНазначения.СообщитьПользователю(
            "Не заполнен контрагент", ЭтотОбъект, "Контрагент", , Отказ);
    КонецЕсли;

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не использовать платформенный `Новый СообщениеПользователю` с последующим
  `Сообщить`: библиотека сама расставит привязку к полю и учтет контекст
  выполнения, в том числе фоновое задание.
- **В `ОбщегоНазначенияКлиентСервер` этой процедуры НЕТ.** Она есть только в
  серверном модуле и в клиентском. Попытка позвать ее из общего модуля даст
  ошибку компиляции.
- Параметр `Отказ` передается по ссылке и взводится процедурой. Взводить его
  отдельно не нужно.

### 3. Работа с коллекциями

**Задача:** объединить структуры, дополнить массив, выгрузить колонку таблицы.

**Функции:**

`ОбщегоНазначенияКлиентСервер.ДополнитьМассив(МассивПриемник, МассивИсточник, ТолькоУникальныеЗначения = Ложь) Экспорт`,
`ОбщегоНазначенияКлиентСервер.ДополнитьСтруктуру(Приемник, Источник, Заменять = Неопределено) Экспорт`,
`ОбщегоНазначенияКлиентСервер.ДополнитьСоответствие(Приемник, Источник, Заменять = Неопределено) Экспорт`,
`ОбщегоНазначенияКлиентСервер.ДополнитьТаблицу(ТаблицаИсточник, ТаблицаПриемник) Экспорт`
- процедуры, регион `ПрограммныйИнтерфейс`. Доступны и на клиенте, и на сервере.

`ОбщегоНазначения.ВыгрузитьКолонку(КоллекцияСтрок, ИмяКолонки, ТолькоУникальныеЗначения = Ложь) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- **Функции `КопироватьРекурсивно` в БСП НЕТ**, проверено. Имя выглядит
  правдоподобно и встречается в чужих подсказках, в том числе в прежней редакции
  описания этого скила. Глубокая копия структуры, соответствия или массива
  делается функцией `ОбщегоНазначения.СкопироватьРекурсивно(Источник, ФиксироватьДанные = Неопределено) Экспорт`
  - разница в одной приставке, и она решает.
- Коллекционные процедуры лежат в `КлиентСервер`, а не в серверном модуле:
  серверный вызов ради них не нужен.

### 4. Выполнить сторонний код в безопасном режиме

**Задача:** исполнить алгоритм из настройки или из внешней обработки, не дав ему
доступа к файловой системе.

**Функции:**

`ОбщегоНазначения.ВыполнитьВБезопасномРежиме(Знач Алгоритм, Знач Параметры = Неопределено, Знач ПараметрыПроверкиАлгоритма = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ОбщегоНазначения.ВыполнитьМетодКонфигурации(Знач ИмяМетода, Знач Параметры = Неопределено, ЭтоФункция = Ложь) Экспорт`
- функция, тот же регион.

**Нюансы и антипаттерны:**

- Не звать платформенный `Выполнить` напрямую для стороннего кода: безопасный
  режим и профили безопасности при этом не действуют.
- У `ВыполнитьМетодКонфигурации` между версиями 3.1.11 и 3.2.1 изменилась форма:
  она стала функцией. Код, написанный по новой сигнатуре, на старой версии
  отработает иначе - смотреть карточку метода в справочнике перед использованием.

### 5. Свойства сеанса и окружения

**Задача:** ветвление по режиму работы: файловая база, модель сервиса, разделение
данных.

**Функции:**

`ОбщегоНазначения.РазделениеВключено() Экспорт`,
`ОбщегоНазначения.ИнформационнаяБазаФайловая() Экспорт`,
`ОбщегоНазначения.ЭтоВебКлиент() Экспорт` - функции, регион
`ПрограммныйИнтерфейс`. Часть из них есть и в клиентском модуле.

**Нюансы и антипаттерны:**

- Не определять режим работы разбором строки соединения: библиотека учитывает и
  модель сервиса, и внешнее соединение.
- Клиентские и серверные варианты этих функций возвращают одно и то же, но
  вызываются из своего контекста. Серверный вызов с клиента ради них не нужен.

## Различия версий

`ОбщегоНазначения.ВыполнитьМетодКонфигурации` между 3.1.11 и 3.2.1 сменила форму:
из процедуры стала функцией. Это ломающее изменение, и справочник `1c-bsp-api`
помечает такие методы отдельно.

Состав модулей семейства в этих версиях совпадает.

## Проверка перед использованием

Модуль большой, и похожие имена в нем встречаются часто. Проверять обязательно:

```bash
python skills/1c-bsp-api/scripts/bsp-api.py check ОбщегоНазначения.ЗначенияРеквизитовОбъектов
```
