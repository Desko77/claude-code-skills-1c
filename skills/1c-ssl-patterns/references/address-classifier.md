# Адресный классификатор

Механизм БСП, работающий с государственным адресным реестром: загруженные регионы,
поиск адресных объектов, коды и наименования, проверка адреса по классификатору.

Работает в паре с контактной информацией: та хранит адрес объекта, этот проверяет
и разбирает его по реестру.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `АдресныйКлассификатор` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `АдресныйКлассификаторКлиент` | клиентская часть | тонкий и толстый клиент |

## Сценарии

### 1. Проверить, загружен ли классификатор

**Задача:** до разбора адреса убедиться, что данные есть.

**Функции:**

`АдресныйКлассификатор.АдресныйКлассификаторЗагружен() Экспорт` - функция, регион
`ПрограммныйИнтерфейс`. Сервер.

`АдресныйКлассификатор.КоличествоЗагруженныхРегионов() Экспорт` - функция, тот же
регион.

**Нюансы и антипаттерны:**

- Классификатор грузится ПО РЕГИОНАМ, а не целиком. Загруженность вообще не
  означает, что есть нужный регион.
- Без проверки разбор адреса тихо вернет пустой результат, и адрес окажется
  введенным в свободной форме.

### 2. Перевести код региона в наименование и обратно

**Задача:** в отчете показать название субъекта по коду из адреса.

**Функции:**

`АдресныйКлассификатор.НаименованиеРегионаПоКоду(КодСубъектаРФ) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`АдресныйКлассификатор.КодРегионаПоНаименованию(Название) Экспорт` - функция, тот
же регион.

**Нюансы и антипаттерны:**

- Не держать свой список регионов константой: коды и наименования меняются, а
  библиотека берет их из загруженного реестра.
- Поиск по наименованию неточен по природе: одно и то же название пишется
  по-разному, и пустой ответ не означает отсутствия региона.

### 3. Получить коды адреса

**Задача:** для выгрузки в госорган нужны коды адресных объектов, а не текст.

**Функции:**

`АдресныйКлассификатор.КодыАдреса(Адрес, Источник = Неопределено) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Адрес, введенный в свободной форме, кодов не имеет. Это видно функцией
  `УправлениеКонтактнойИнформацией.АдресВведенВСвободнойФорме`.
- Источник кодов различается между реестрами. Полагаться на источник по умолчанию
  при выгрузке в госорган нельзя.

## Различия версий

Состав модулей семейства в 3.1.11 и 3.2.1 совпадает - сверено по обеим поставкам.
