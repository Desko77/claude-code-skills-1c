# Шаблоны сообщений

Механизм БСП, формирующий письма и сообщения по шаблону: пользователь заводит
текст с подстановками, библиотека заполняет их данными объекта и собирает готовое
сообщение с вложениями и получателями.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ШаблоныСообщений` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `ШаблоныСообщенийКлиентСервер` | общие правила разбора шаблонов | сервер и клиент |
| `ШаблоныСообщенийПереопределяемый` | точка расширения: свои параметры шаблонов | сервер, толстый клиент, внешнее соединение |

## Сценарии

### 1. Подставить значения в текст шаблона

**Задача:** заполнить заготовку письма данными документа.

**Функции:**

`ШаблоныСообщений.ВставитьПараметрыВСтрокуСогласноТаблицеПараметров(Знач ШаблонСтроки, ВставляемыеЗначения, Знач Префикс = "") Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Не собирать текст конкатенацией и `СтрЗаменить`: шаблон заводит пользователь, и
  имена параметров в нем произвольные, а разбор учитывает вложенность и префиксы.
- Незаполненный параметр остается в тексте как есть. Проверять результат на
  остатки подстановок надо до отправки.

### 2. Объявить свои параметры шаблона

**Задача:** в шаблоне должны быть доступны поля своего документа.

**Функции:**

`ШаблоныСообщений.ДобавитьПараметрШаблона(ТаблицаПараметров, ИмяПараметра, ОписаниеТипа, ЭтоПредопределенныйПараметр, ПредставлениеПараметра = "") Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ШаблоныСообщений.ЗаполнитьРеквизитыПоСКД(Реквизиты, Предмет, ПараметрыШаблона) Экспорт`
- процедура, тот же регион: набор параметров берется из схемы компоновки.

**Нюансы и антипаттерны:**

- Представление параметра видит пользователь при вставке. Пустое представление
  оставляет его наедине с техническим именем.
- Тип параметра не декоративен: по нему библиотека форматирует значение при
  подстановке.

### 3. Заполнить получателей письма

**Задача:** взять адреса из контактной информации объекта.

**Функции:**

`ШаблоныСообщений.ЗаполнитьПолучателей(ПолучателиПисьма, ПредметСообщения, ИмяРеквизита, ТипКонтактнойИнформации = Неопределено, ВариантОтправки = "Кому") Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Адреса берутся из механизма контактной информации, а не из реквизита строкой.
  Прямое чтение реквизита пропустит объекты с несколькими адресами.
- Вариант отправки различает основных получателей и копии. По умолчанию все
  попадают в основные.

## Различия версий

Состав модулей семейства в 3.1.11 и 3.2.1 совпадает - сверено по обеим поставкам.
