# Подключаемые команды

Механизм БСП, позволяющий одной подсистеме добавить команду на форму объекта,
принадлежащего другой подсистеме: печать, отправка почтой, создание на основании,
дополнительные обработки. Форма объекта при этом ничего о них не знает.

Через этот механизм на форму попадают команды печати и команды дополнительных
обработок - они не отдельные механизмы размещения, а его потребители.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ПодключаемыеКоманды` | программный интерфейс сервера: сбор состава и размещение | сервер, толстый клиент, внешнее соединение |
| `ПодключаемыеКомандыКлиент` | программный интерфейс клиента: выполнение команды | тонкий и толстый клиент |
| `ПодключаемыеКомандыКлиентСервер` | общая часть | сервер и клиент |
| `ПодключаемыеКомандыПереопределяемый` | точка расширения: свои виды команд | сервер, толстый клиент, внешнее соединение |
| `ПодключаемыеКомандыГлобальный`, `...ВызовСервера`, `...ПовтИсп`, `...КлиентПовтИсп` | внутренняя реализация библиотеки | - |

## Сценарии

### 1. Подключить механизм к своей форме

**Задача:** на форме своего документа должны появиться команды печати, отправки
и дополнительных обработок.

**Функции:**

`ПодключаемыеКоманды.ПриСозданииНаСервере(Форма, Знач ПараметрыРазмещения = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ПодключаемыеКоманды.ПараметрыРазмещения() Экспорт` - функция-конструктор, тот же
регион.

**Пример:**

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

    ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтаФорма);

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Один вызов подключает ВСЕ команды сразу: печать, почту, дополнительные
  обработки. Отдельно подключать печать не нужно и неверно.
- Параметры размещения задают, в какие группы формы попадут команды. Без них
  библиотека выбирает группы сама, и на нестандартной форме результат бывает не
  тем, что ожидался.

### 2. Выполнить подключаемую команду

**Задача:** обработчик команды на форме должен передать управление библиотеке.

**Функции:**

`ПодключаемыеКомандыКлиент.ВыполнитьКоманду(Форма, Команда, Источник) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Клиент.

`ПодключаемыеКомандыКлиент.НачатьВыполнениеКоманды(Форма, Команда, Знач Источник = Неопределено) Экспорт`
- процедура, тот же регион: асинхронный вариант.

`ПодключаемыеКоманды.ВыполнитьКоманду(Знач Форма, Знач ПараметрыВызова, Знач Источник = Неопределено, Результат = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Обработчик команды на форме создается библиотекой, свой писать не нужно. Своя
  реализация появляется только тогда, когда команда нетиповая.
- Клиентский и серверный `ВыполнитьКоманду` это РАЗНЫЕ процедуры с разными
  сигнатурами. Путать их легко: имена совпадают.

### 3. Обновить состав команд после записи

**Задача:** после проведения документа набор доступных команд меняется.

**Функции:**

`ПодключаемыеКомандыКлиент.ПослеЗаписи(Форма, Объект, ПараметрыЗаписи) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Клиент.

`ПодключаемыеКомандыКлиент.НачатьОбновлениеКоманд(Форма, Элемент = Неопределено, Строка = Неопределено) Экспорт`
- процедура, тот же регион.

**Нюансы и антипаттерны:**

- Без вызова после записи команды останутся в состоянии, которое было до нее:
  например печать будет недоступна у только что записанного документа.
- Обновление асинхронное. Проверять доступность команды сразу после вызова
  бессмысленно.

### 4. Ограничить видимость команды

**Задача:** команда должна показываться только для определенного вида операции.

**Функции:**

`ПодключаемыеКоманды.ДобавитьУсловиеВидимостиКоманды(Команда, Реквизит, Значение = Неопределено, Знач ВидСравнения = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Условие вычисляет библиотека по реквизиту объекта. Свой код в форме для того же
  отработает на каждое открытие, а условие - один раз на список.
- Условие видимости это не право доступа. Скрытая команда остается вызываемой,
  если пользователь дотянется до нее иначе.

### 5. Объявить свой вид подключаемых команд

**Задача:** своя подсистема должна добавлять команды на чужие формы.

**Функции:**

`ПодключаемыеКомандыПереопределяемый.ПриОпределенииВидовПодключаемыхКоманд(ВидыПодключаемыхКоманд) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

`ПодключаемыеКомандыПереопределяемый.ПриОпределенииКомандПодключенныхКОбъекту(НастройкиФормы, Источники, ПодключенныеОтчетыИОбработки, Команды) Экспорт`
- процедура, тот же регион и та же роль.

**Нюансы и антипаттерны:**

- Не вызывать процедуры `ПодключаемыеКомандыПереопределяемый` из прикладного
  кода: их реализуют.
- Хук вызывается для КАЖДОЙ формы, куда подключен механизм. Тяжелая работа в нем
  замедляет открытие всех таких форм, а не только своей.

## Различия версий

Состав модулей семейства в 3.1.11 и 3.2.1 совпадает - сверено по обеим поставкам.
