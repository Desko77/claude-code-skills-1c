# Запрет редактирования реквизитов объектов

Механизм БСП, блокирующий на форме ключевые реквизиты после того, как объект
проведен или уже использован: организация, склад, договор. Пользователь видит
кнопку разблокировки и снимает запрет осознанно, а не правит поле случайно.

Не путать с датами запрета изменения: там запрет по периоду для всего объекта,
здесь блокировка отдельных полей на форме.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ЗапретРедактированияРеквизитовОбъектов` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `ЗапретРедактированияРеквизитовОбъектовКлиент` | программный интерфейс клиента: разблокировка на форме | тонкий и толстый клиент |
| `ЗапретРедактированияРеквизитовОбъектовПереопределяемый` | точка расширения: свои запрещенные реквизиты | сервер, толстый клиент, внешнее соединение |
| `ЗапретРедактированияРеквизитовОбъектовСлужебный`, `...СлужебныйКлиент` | внутренняя реализация библиотеки | - |

Серверный модуль здесь маленький - три метода. Основная работа на клиенте: запрет
это состояние формы, а не данных.

## Сценарии

### 1. Заблокировать реквизиты на форме объекта

**Задача:** после проведения документа ключевые поля должны стать недоступными.

**Функции:**

`ЗапретРедактированияРеквизитовОбъектов.ЗаблокироватьРеквизиты(Форма, ГруппаДляКнопкиЗапрета = Неопределено, ЗаголовокКнопкиЗапрета = "", Объект = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Пример:**

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

    ЗапретРедактированияРеквизитовОбъектов.ЗаблокироватьРеквизиты(ЭтаФорма);

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Вызов идет в `ПриСозданииНаСервере` формы: библиотека добавляет на форму кнопку
  разблокировки, а элементы к моменту открытия должны быть на месте.
- Не гасить доступность полей своим кодом: тогда пользователь не получит кнопку
  разблокировки и не сможет исправить ошибку ввода вовсе.

### 2. Объявить, какие реквизиты блокируются

**Задача:** для своего документа задать перечень ключевых полей.

**Функции:**

`ЗапретРедактированияРеквизитовОбъектовПереопределяемый.ПриОпределенииОбъектовСЗаблокированнымиРеквизитами(Объекты) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

`ЗапретРедактированияРеквизитовОбъектовПереопределяемый.ПриОпределенииЗаблокированныхРеквизитов(ИмяОбъектаМетаданных, ЗаблокированныеРеквизиты) Экспорт`
- процедура, тот же регион и та же роль.

`ЗапретРедактированияРеквизитовОбъектов.НовыйБлокируемыйРеквизит() Экспорт`
- функция-конструктор, регион `ПрограммныйИнтерфейс`.

`ЗапретРедактированияРеквизитовОбъектов.БлокируемыеРеквизитыОбъекта(ИмяОбъекта) Экспорт`
- функция, тот же регион: что уже объявлено.

**Пример:**

```bsl
// Модуль ЗапретРедактированияРеквизитовОбъектовПереопределяемый, тело хука.
Процедура ПриОпределенииЗаблокированныхРеквизитов(ИмяОбъектаМетаданных, ЗаблокированныеРеквизиты) Экспорт

    Если ИмяОбъектаМетаданных = "Документ.РасходТовара" Тогда
        Реквизит = ЗапретРедактированияРеквизитовОбъектов.НовыйБлокируемыйРеквизит();
        Реквизит.Имя = "Организация";
        ЗаблокированныеРеквизиты.Добавить(Реквизит);
    КонецЕсли;

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Объект должен быть назван в ОБОИХ хуках: сначала в перечне объектов, затем в
  перечне его реквизитов. Пропуск первого выглядит как работающий механизм без
  блокировок.
- Не вызывать процедуры переопределяемого модуля из прикладного кода: их
  реализуют.

### 3. Разблокировать реквизиты по действию пользователя

**Задача:** своя команда должна снимать запрет так же, как типовая кнопка.

**Функции:**

`ЗапретРедактированияРеквизитовОбъектовКлиент.РазрешитьРедактированиеРеквизитовОбъекта(Знач Форма, ОбработкаПродолжения = Неопределено, ТолькоВидимые = Истина) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Клиент.

`ЗапретРедактированияРеквизитовОбъектовКлиент.УстановитьДоступностьЭлементовФормы(Знач Форма, Знач Реквизиты = Неопределено) Экспорт`
- процедура, тот же регион.

`ЗапретРедактированияРеквизитовОбъектовКлиент.Реквизиты(Знач Форма, Знач ТолькоЗаблокированные = Истина, ТолькоВидимые = Истина) Экспорт`
- функция, тот же регион.

**Нюансы и антипаттерны:**

- Разблокировка асинхронная: пользователю задается вопрос, и результат приходит
  в обработку продолжения. Код после вызова выполняется ДО ответа.
- Не звать серверный модуль механизма с клиента: у него нет контекста тонкого
  клиента, а разблокировка это клиентское действие.

## Различия версий

Состав модулей и их экспортные методы в 3.1.11 и 3.2.1 совпадают - сверено по
обеим поставкам.
