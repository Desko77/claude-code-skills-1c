# Управление доступом

Механизм БСП, ограничивающий доступ на уровне записей и полей: профили групп
доступа, виды доступа, наборы значений доступа. Отвечает на вопрос "какие данные
видит этот пользователь", тогда как роли платформы отвечают на вопрос "какие
действия ему вообще разрешены".

Не путать с механизмом `Пользователи`: там учетные записи и текущий пользователь,
здесь права на данные.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `УправлениеДоступом` | программный интерфейс | сервер, толстый клиент, внешнее соединение |
| `УправлениеДоступомПереопределяемый` | точка расширения: свои виды доступа и наборы значений | сервер, толстый клиент, внешнее соединение |
| `УправлениеДоступомСлужебный` и еще шесть с тем же началом | внутренняя реализация библиотеки | - |

**Публичного клиентского модуля у механизма нет.** `УправлениеДоступомСлужебныйКлиент`
и `УправлениеДоступомСлужебныйКлиентСервер` служебные, как и говорит их имя.
Проверку прав выполняет сервер, и клиент получает уже результат.

## Сценарии

### 1. Проверить право пользователя на конкретный объект

**Задача:** до выполнения действия убедиться, что у пользователя есть право на
ЭТУ запись, а не вообще на вид объекта.

**Функции:**

`УправлениеДоступом.ЕстьПраво(Право, СсылкаНаОбъект, Знач Пользователь = Неопределено) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеДоступом.ИзменениеРазрешено(ОписаниеДанных, Пользователь = Неопределено) Экспорт`
- функция, тот же регион.

**Параметры:**

- `Право` - `Строка`: чтение, изменение и прочие.
- `СсылкаНаОбъект` - ссылка на конкретную запись.
- `Пользователь` - `Неопределено` означает текущего.

**Пример:**

```bsl
&НаСервере
Функция МожноПравитьДокумент(Знач Ссылка)

    Возврат УправлениеДоступом.ЕстьПраво("Изменение", Ссылка);

КонецФункции
```

**Нюансы и антипаттерны:**

- Не подменять эту проверку платформенной `ПравоДоступа`: та отвечает на вопрос о
  виде объекта целиком и про ограничение на уровне записей ничего не знает.
- Не считать отсутствие права ошибкой программы: это штатный ответ, и пользователю
  показывается сообщение, а не исключение.

### 2. Проверить роль пользователя

**Задача:** ветвление логики по роли, а не по конкретному праву.

**Функции:**

`УправлениеДоступом.ЕстьРоль(Знач Роль, Знач СсылкаНаОбъект = Неопределено, Знач Пользователь = Неопределено) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Пример:**

```bsl
&НаСервере
Функция ЭтоКладовщик()

    Возврат УправлениеДоступом.ЕстьРоль("ДобавлениеИзменениеСкладскихДокументов");

КонецФункции
```

**Нюансы и антипаттерны:**

- Ветвление по роли - крайняя мера. Право на данные проверяется правом, а не
  ролью: роль может называться иначе во внедрении, а право останется прежним.
- Полноту прав проверяют не ролью, а `Пользователи.ЭтоПолноправныйПользователь`.

### 3. Назначить пользователю профиль группы доступа

**Задача:** при создании пользователя из кода выдать ему набор прав.

**Функции:**

`УправлениеДоступом.ВключитьПрофильПользователю(Пользователь, Профиль) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеДоступом.ВыключитьПрофильПользователю(Пользователь, Профиль = Неопределено) Экспорт`
- процедура, тот же регион. Без профиля выключает все.

`УправлениеДоступом.ГруппаДоступаАдминистраторы() Экспорт` - функция, тот же
регион.

**Пример:**

```bsl
&НаСервере
Процедура ВыдатьПрофильСкладовщика(Знач Пользователь)

    Профиль = Справочники.ПрофилиГруппДоступа.НайтиПоНаименованию("Кладовщик");
    Если ЗначениеЗаполнено(Профиль) Тогда
        УправлениеДоступом.ВключитьПрофильПользователю(Пользователь, Профиль);
    КонецЕсли;

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не добавлять пользователя в группу доступа записью справочника напрямую: у
  библиотеки на это своя логика пересчета прав, и запись мимо нее оставит права
  неактуальными.
- Пересчет прав идет фоново. Сразу после назначения профиля новые ограничения
  могут еще не действовать.

### 4. Заполнить наборы значений доступа своего объекта

**Задача:** свой документ должен ограничиваться по тем же видам доступа, что и
типовые.

**Функции:**

Наборы значений доступа заполняются в модуле САМОГО объекта, процедурой
`ЗаполнитьНаборыЗначенийДоступа`, а не в переопределяемом модуле подсистемы. В
`УправлениеДоступомПереопределяемый` метода с таким именем НЕТ - там объявляют
виды доступа и списки с ограничением, а не наборы конкретного объекта.

`УправлениеДоступом.ЗаполнитьНаборыЗначенийДоступа(Знач Объект, Таблица, Знач СсылкаНаПодчиненныйОбъект = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеДоступом.ДобавитьНаборыЗначенийДоступа(Приемник, Знач Источник, Знач Умножение = Ложь, Знач Упростить = Ложь) Экспорт`
- процедура, тот же регион: складывает наборы, в том числе умножением.

`УправлениеДоступомПереопределяемый.ПриЗаполненииСписковСОграничениемДоступа(Списки) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК: им объявляют, что объект вообще
участвует в ограничении доступа.

`УправлениеДоступомПереопределяемый.ПриЗаполненииВидовДоступа(ВидыДоступа) Экспорт`
- процедура, тот же регион и та же роль: объявляет свой вид доступа.

**Нюансы и антипаттерны:**

- Не вызывать процедуры `УправлениеДоступомПереопределяемый` из прикладного кода:
  их реализуют.
- Объект, не объявленный в `ПриЗаполненииСписковСОграничениемДоступа`, наборы
  значений не получит, и ограничение на него не подействует. Ошибки при этом нет.
- Набор значений доступа пересчитывается при записи объекта. Правка данных мимо
  записи объекта оставит набор старым.

### 5. Запланировать пересчет прав после массовой правки

**Задача:** после загрузки или групповой обработки права должны пересчитаться.

**Функции:**

`УправлениеДоступом.ЗапланироватьОбновлениеДоступа(Таблица) Экспорт` - процедура,
регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Не пересчитывать права синхронно в цикле по объектам: библиотека делает это
  фоново и пакетно, а поштучный пересчет на больших объемах занимает часы.
- После планирования пересчет идет регламентным заданием. Выключенное задание -
  права не обновятся вовсе.

## Различия версий
