# Свойства: дополнительные реквизиты и сведения

Механизм БСП, позволяющий пользователю добавить объекту поля без изменения
конфигурации: дополнительные реквизиты хранятся в самом объекте, дополнительные
сведения - отдельно от него.

Разница между ними существенна. ДопРеквизит принадлежит объекту и записывается
вместе с ним; ДопСведение хранится в регистре и правится независимо, в том числе
когда сам объект править нельзя.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `УправлениеСвойствами` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `УправлениеСвойствамиКлиент` | программный интерфейс клиента: правка значений на форме | тонкий и толстый клиент |
| `УправлениеСвойствамиПереопределяемый` | точка расширения: свои наборы свойств | сервер, толстый клиент, внешнее соединение |
| `УправлениеСвойствамиПовтИсп`, `УправлениеСвойствамиСлужебный` | внутренняя реализация библиотеки | - |

**Модуля `Свойства` не существует**, хотя подсистема называется именно так. Все
методы лежат в `УправлениеСвойствами` и его семействе.

## Сценарии

### 1. Прочитать значение дополнительного свойства

**Задача:** в отчете или в проведении использовать поле, добавленное
пользователем.

**Функции:**

`УправлениеСвойствами.ЗначениеСвойства(Объект, Свойство, КодЯзыка = "") Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеСвойствами.ЗначенияСвойств(ОбъектыСоСвойствами, ПолучатьДопРеквизиты = Истина, ПолучатьДопСведения = Истина, Свойства = Неопределено, КодЯзыка = "") Экспорт`
- функция, тот же регион: для нескольких объектов и свойств сразу.

**Пример:**

```bsl
&НаСервере
Функция ЗначениеДопРеквизита(Знач Ссылка, Знач Свойство)

    Возврат УправлениеСвойствами.ЗначениеСвойства(Ссылка, Свойство);

КонецФункции
```

**Нюансы и антипаттерны:**

- Не читать табличную часть дополнительных реквизитов объекта запросом напрямую:
  дополнительные СВЕДЕНИЯ там не лежат, они в отдельном регистре, и запрос их
  пропустит.
- Для списка объектов брать `ЗначенияСвойств`, а не звать одиночную функцию в
  цикле: она читает регистр на каждый вызов.

### 2. Записать значения свойств объекту

**Задача:** загрузка из внешней системы должна заполнять пользовательские поля.

**Функции:**

`УправлениеСвойствами.ЗаписатьСвойстваУОбъекта(ВладелецСвойств, ТаблицаСвойствИЗначений) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеСвойствами.ДобавитьЗначениеСвойства(Знач Владелец, Параметры, Иерархия = Ложь) Экспорт`
и `УправлениеСвойствами.ПараметрыДобавленияЗначенияСвойства() Экспорт`
- функции, тот же регион: добавление нового значения в список значений свойства.

**Нюансы и антипаттерны:**

- Не записывать регистр дополнительных сведений набором записей напрямую: у
  библиотеки своя логика по видам свойств и по иерархии значений.
- Значение должно быть допустимого типа для этого свойства. Библиотека проверяет
  это при записи, а прямая запись в регистр - нет.

### 3. Вывести свойства на форму

**Задача:** на форме своего объекта показать пользовательские поля так же, как в
типовых.

**Функции:**

`УправлениеСвойствами.ЗаполнитьДополнительныеРеквизитыВФорме(Форма, Объект = Неопределено, ПоляНадписей = Ложь, СкрытьУдаленные = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеСвойствами.ПеренестиЗначенияИзРеквизитовФормыВОбъект(Форма, Объект = Неопределено) Экспорт`
- процедура, тот же регион: обратный перенос перед записью.

`УправлениеСвойствамиКлиент.ОбновитьЗависимостиДополнительныхРеквизитов(Форма, Объект = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Клиент.

**Нюансы и антипаттерны:**

- Перенос значений с формы в объект вызывается ПЕРЕД записью. Пропуск этого шага
  выглядит как потеря введенных значений без ошибки.
- Свойства выводятся на форму динамически, элементы создаются библиотекой.
  Обращаться к ним по имени из своего кода нельзя: имена генерируемые.

### 4. Задать свои наборы свойств

**Задача:** у своего документа должны быть отдельные наборы свойств по видам
операции.

**Функции:**

`УправлениеСвойствамиПереопределяемый.ЗаполнитьНаборыСвойствОбъекта(Знач Объект, ТипСсылки, НаборыСвойств, СтандартнаяОбработка, КлючНазначения) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

`УправлениеСвойствамиПереопределяемый.ПриПолученииПредопределенныхНаборовСвойств(Наборы) Экспорт`
- процедура, тот же регион и та же роль.

**Нюансы и антипаттерны:**

- Не вызывать процедуры `УправлениеСвойствамиПереопределяемый` из прикладного
  кода: их реализуют.
- Хук вызывается при каждом открытии формы объекта. Запросы в нем идут на каждое
  открытие, и тяжелая выборка там заметна пользователю.

## Различия версий

Состав модулей и их экспортные методы в 3.1.11 и 3.2.1 совпадают - сверено по
обеим поставкам.
