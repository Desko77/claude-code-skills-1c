# Электронная подпись

Механизм БСП, подписывающий объекты и файлы криптографической подписью:
сертификаты, интерактивное подписание, проверка подписи, штампы в печатных формах,
работа через облачный сервис подписи.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ЭлектроннаяПодпись` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `ЭлектроннаяПодписьКлиент` | программный интерфейс клиента: интерактивное подписание и проверка, установка расширения криптографии | тонкий и толстый клиент |
| `ЭлектроннаяПодписьКлиентЛокализация` | национальная специфика клиента, 74 метода | тонкий и толстый клиент |
| `ЭлектроннаяПодписьПереопределяемый` | точка расширения | сервер, толстый клиент, внешнее соединение |

**Подписание интерактивное по природе.** Закрытый ключ находится у пользователя,
поэтому подписать объект серверным кодом без участия клиента нельзя. Серверные
методы работают с УЖЕ полученной подписью.

## Сценарии

### 1. Добавить подпись к объекту

**Задача:** сохранить полученную от пользователя подпись рядом с документом.

**Функции:**

`ЭлектроннаяПодпись.ДобавитьПодпись(Объект, Знач СвойстваПодписи, ИдентификаторФормы = Неопределено, ВерсияОбъекта = Неопределено, ЗаписанныйОбъект = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Свойства подписи собирает КЛИЕНТ через `ЭлектроннаяПодписьКлиент`: закрытый ключ
  на сервер не передается.
- Версия объекта не декоративна: подпись относится к конкретному состоянию данных,
  и после правки объекта она перестает быть действительной.

### 2. Прочитать сведения о подписи

**Задача:** показать в интерфейсе, кто и когда подписал.

**Функции:**

`ЭлектроннаяПодпись.ДатаПодписания(Подпись, ПривестиКЧасовомуПоясуСеанса = Истина) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Дата подписания берется ИЗ ПОДПИСИ, а не из момента записи объекта. Это разные
  моменты, и расхождение между ними нормально.
- Приведение к часовому поясу сеанса включено по умолчанию. При сравнении подписей
  из разных баз его отключают.

### 3. Поставить штамп подписи в печатную форму

**Задача:** в печатной накладной показать отметку о подписании.

**Функции:**

`ЭлектроннаяПодпись.ДобавитьШтампыВТабличныйДокумент(Документ, ОписаниеШтампов, Размеры = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Штамп рисуется в уже сформированный табличный документ. Место под него в макете
  предусматривается заранее, иначе штамп наложится на текст.

### 4. Записать сертификат в справочник

**Задача:** зарегистрировать сертификат пользователя для дальнейшего подписания.

**Функции:**

`ЭлектроннаяПодпись.ЗаписатьСертификатВСправочник(Знач Сертификат, ДополнительныеПараметры = Неопределено) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Сертификат читается на клиенте через криптографию и передается на сервер уже
  разобранным. Читать хранилище сертификатов серверным кодом нельзя: его там нет.
- Не создавать элемент справочника сертификатов записью объекта: библиотека
  разбирает отпечаток, срок действия и владельца.

## Различия версий

Состав модулей семейства в 3.1.11 и 3.2.1 совпадает - сверено по обеим поставкам.
