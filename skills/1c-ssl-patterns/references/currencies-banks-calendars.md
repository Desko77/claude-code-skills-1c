# Валюты, банки, графики и календари

Четыре механизма БСП, объединенные тем, что все они дают справочные данные и
расчеты по ним: курсы валют, классификатор банков, графики работы организации,
производственный календарь.

**Имена модулей здесь не совпадают с названиями подсистем** - это главное расхождение
в теме. Подсистема называется "Валюты", а модуль `РаботаСКурсамиВалют`; подсистема
"Банки", а модуль `РаботаСБанками`. Модулей `Валюты` и `Банки` в библиотеке НЕТ,
проверено по обеим поставкам.

## Модули

| Модуль | Механизм | Контексты |
|---|---|---|
| `РаботаСКурсамиВалют` | курсы валют: загрузка, пересчет, сумма прописью | сервер, толстый клиент, внешнее соединение |
| `РаботаСКурсамиВалютЛокализация` | национальная специфика курсов | сервер |
| `РаботаСБанками` | классификатор банков: поиск по БИК и корсчету | сервер, толстый клиент, внешнее соединение |
| `РаботаСБанкамиПереопределяемый` | точка расширения классификатора | сервер |
| `ГрафикиРаботы` | графики работы организации, расчет дат по графику | сервер, толстый клиент, внешнее соединение |
| `КалендарныеГрафики` | производственный календарь, рабочие даты | сервер, толстый клиент, внешнее соединение |

## Сценарии

### 1. Пересчитать сумму в другую валюту

**Задача:** привести сумму документа к валюте учета на дату документа.

**Функции:**

`РаботаСКурсамиВалют.ПересчитатьВВалюту(Сумма, ИсходнаяВалюта, НоваяВалюта, Дата) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`РаботаСКурсамиВалют.ПолучитьКурсВалюты(Валюта, ДатаКурса) Экспорт` - функция, тот
же регион.

**Нюансы и антипаттерны:**

- Не читать регистр курсов валют запросом и не делить самостоятельно: курс имеет
  кратность, и деление без нее дает неверный результат.
- Курс берется НА ДАТУ. Пересчет по текущему курсу задним числом искажает
  историю.

### 2. Сумма прописью

**Задача:** в печатной форме вывести сумму словами с валютой.

**Функции:**

`РаботаСКурсамиВалют.СформироватьСуммуПрописью(СуммаЧислом, Валюта, БезДробнойЧасти = Ложь, Знач КодЯзыка = Неопределено, ДробнаяЧастьПрописью = Ложь) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Не собирать строку платформенным `ЧислоПрописью` со своим шаблоном: параметры
  прописи зависят от валюты и языка, и библиотека берет их из справочника валют.

### 3. Найти банк по БИК

**Задача:** при вводе реквизитов подставить наименование и корсчет банка.

**Функции:**

Модуль `РаботаСБанками`, регион `ПрограммныйИнтерфейс`. Сервер. Интерфейс узкий -
два метода: поиск по классификатору и загрузка самого классификатора.

**Нюансы и антипаттерны:**

- Классификатор может быть не загружен. Пустой результат поиска это штатный
  ответ, а не отсутствие банка.
- Не хранить наименование банка реквизитом рядом с БИК: оно меняется, и
  расхождение всплывет в платежных документах.

### 4. Рассчитать дату по графику работы

**Задача:** срок исполнения через пять рабочих дней с учетом выходных.

**Функции:**

`ГрафикиРаботы.ДатаПоГрафику(Знач ГрафикРаботы, Знач ДатаОт, Знач КоличествоДней, ВызыватьИсключение = Истина) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`ГрафикиРаботы.ДатыПоГрафику(Знач ГрафикРаботы, Знач ДатаОт, Знач МассивДней, Знач РассчитыватьСледующуюДатуОтПредыдущей = Ложь, ВызыватьИсключение = Истина) Экспорт`
- функция, тот же регион: несколько сроков сразу.

`ГрафикиРаботы.БлижайшиеДатыВключенныеВГрафик(ГрафикРаботы, НачальныеДаты, ПараметрыПолучения = Неопределено) Экспорт`
- функция, тот же регион.

**Нюансы и антипаттерны:**

- Для нескольких дат брать множественную функцию: одиночная в цикле читает график
  на каждый вызов.
- График может быть не заполнен на нужный период. Параметр `ВызыватьИсключение`
  решает, будет это ошибкой или пустым ответом - выбирать осознанно.

### 5. Рабочие даты по производственному календарю

**Задача:** то же, но по государственному календарю, а не по графику
организации.

**Функции:**

`КалендарныеГрафики.ДатаПоКалендарю(Знач ГрафикРаботы, Знач ДатаОт, Знач КоличествоДней, ВызыватьИсключение = Истина) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`КалендарныеГрафики.БлижайшиеРабочиеДаты(ПроизводственныйКалендарь, НачальныеДаты, ПараметрыПолучения = Неопределено) Экспорт`
- функция, тот же регион.

`КалендарныеГрафики.ОсновнойПроизводственныйКалендарь() Экспорт` - функция, тот же
регион.

**Нюансы и антипаттерны:**

- График работы и производственный календарь это РАЗНЫЕ механизмы с похожими
  функциями. График принадлежит организации, календарь государственный.
- Календарь заполняется на год вперед. Расчет за его пределами даст исключение
  либо пустоту в зависимости от параметра.

## Различия версий

Состав модулей всех четырех механизмов в 3.1.11 и 3.2.1 совпадает - сверено по
обеим поставкам.
