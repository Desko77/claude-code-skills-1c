# Точки расширения без своего интерфейса

Пять механизмов БСП, у которых прикладному коду доступна ТОЛЬКО точка расширения:
интерфейс OData, информация при запуске, отчет о движениях документа, проверка
легальности обновления, а также ручной порядок элементов в списках.

Общее у них: механизм работает сам, а конфигурация лишь объявляет свое участие в
нем. Вызывать эти модули из прикладного кода не нужно и почти всегда неверно.

## Модули

| Модуль | Механизм | Контексты |
|---|---|---|
| `ИнтерфейсODataПереопределяемый` | состав публикуемых объектов OData | сервер, толстый клиент, внешнее соединение |
| `ИнформацияПриЗапускеПереопределяемый` | информационные сообщения при запуске | сервер, толстый клиент, внешнее соединение |
| `ОтчетОДвиженияхДокументаПереопределяемый` | состав регистров в отчете о движениях | сервер, толстый клиент, внешнее соединение |
| `ПроверкаЛегальностиПолученияОбновленияКлиент` | проверка легальности обновления, клиентская часть | тонкий и толстый клиент |
| `НастройкаПорядкаЭлементов` | ручной порядок элементов в списках | сервер, толстый клиент, внешнее соединение |

## Сценарии

### 1. Объявить зависимые таблицы для OData

**Задача:** при публикации объекта через OData вместе с ним должны выгружаться
связанные таблицы.

**Функции:**

`ИнтерфейсODataПереопределяемый.ПриЗаполненииЗависимыхТаблицДляВыгрузкиЗагрузкиOData(Таблицы) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК. Единственный метод модуля.

**Нюансы и антипаттерны:**

- Не вызывать этот хук из прикладного кода: его реализуют.
- Незаявленная зависимая таблица выгрузится пустой, и внешняя система получит
  неполные данные без ошибки.

### 2. Показать сообщение при запуске

**Задача:** предупредить пользователей о предстоящих работах.

**Функции:**

`ИнформацияПриЗапускеПереопределяемый.ОпределитьНастройки(Настройки) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК. Единственный метод модуля.

**Нюансы и антипаттерны:**

- Сообщение показывается КАЖДОМУ при запуске. Тяжелый запрос в этом хуке
  замедляет вход всем пользователям.
- Не выводить сообщение своим кодом при начале работы системы: библиотека
  запоминает, что пользователь его уже видел.

### 3. Дополнить отчет о движениях документа

**Задача:** в отчете о движениях показать свой регистр.

**Функции:**

`ОтчетОДвиженияхДокументаПереопределяемый.ПриОпределенииРегистровСДвижениями(Документ, РегистрыСДвижениями) Экспорт`,
`ОтчетОДвиженияхДокументаПереопределяемый.ПриПодготовкеНабораДанных(Документ, НаборыДанных) Экспорт`,
`ОтчетОДвиженияхДокументаПереопределяемый.ПриРасчетеКоличестваЗаписей(Документ, РассчитанноеКоличество) Экспорт`
- процедуры, регион `ПрограммныйИнтерфейс`. ХУКИ.

**Нюансы и антипаттерны:**

- Хуки вызываются на КАЖДОЕ открытие отчета. Подсчет записей запросом по всей
  таблице делает отчет медленным.
- Не вызывать процедуры этого модуля из прикладного кода: их реализуют.

### 4. Ручной порядок элементов в списке

**Задача:** пользователь двигает строки справочника вверх и вниз, и порядок
сохраняется.

**Функции:**

`НастройкаПорядкаЭлементов.УстановитьЗначениеРеквизитаУпорядочивания(Объект) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`НастройкаПорядкаЭлементов.СброситьЗначениеРеквизитаУпорядочивания(Источник, ОбъектКопирования) Экспорт`
- процедура, тот же регион: обработчик подписки при копировании.

`НастройкаПорядкаЭлементов.ПолучитьИнформациюДляПеремещения(МетаданныеОбъекта) Экспорт`
- функция, тот же регион.

**Нюансы и антипаттерны:**

- Реквизит упорядочивания заполняет библиотека. Своя нумерация разъедется при
  вставке между элементами.
- Копия элемента НЕ должна наследовать порядок оригинала: для этого и нужна
  процедура сброса, подключаемая подпиской.

### 5. Проверка легальности обновления

**Задача:** библиотека спрашивает пользователя, легально ли получено обновление.

**Механизм:** модуль `ПроверкаЛегальностиПолученияОбновленияКлиент`, клиентская
часть. Вызывается сценарием обновления, а не прикладным кодом.

**Нюансы и антипаттерны:**

- Вопрос задается пользователю интерактивно. Ответ на него серверным кодом
  подменять нельзя.

## Различия версий

Состав модулей всех пяти механизмов в 3.1.11 и 3.2.1 совпадает - сверено по обеим
поставкам.
