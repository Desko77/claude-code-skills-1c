# Печать

Механизм БСП, формирующий печатные формы: команды печати в объекте, макеты в
табличном документе и в форматах офисных документов, предварительный просмотр,
отправка на принтер и почтой.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `УправлениеПечатью` | программный интерфейс сервера, самый большой модуль механизма | сервер, толстый клиент, внешнее соединение |
| `УправлениеПечатьюКлиент` | программный интерфейс клиента: выполнение команд, просмотр | тонкий и толстый клиент |
| `УправлениеПечатьюПереопределяемый` | точка расширения сервера: свои формы и команды, подмена макетов | сервер, толстый клиент, внешнее соединение |
| `УправлениеПечатьюКлиентПереопределяемый` | точка расширения клиента | тонкий и толстый клиент |
| `УправлениеПечатьюМультиязычностьПереопределяемый` | многоязычность печатных форм | сервер |
| `УправлениеПечатьюРФ` | национальная специфика | сервер |

**Команды печати объявляются в модуле МЕНЕДЖЕРА объекта**, процедурой
`ДобавитьКомандыПечати(КомандыПечати)`, а не в переопределяемом модуле
подсистемы. Переопределяемый модуль нужен, чтобы вмешаться в уже собранный
список или в сам процесс печати.

## Сценарии

### 1. Объявить команду печати у своего объекта

**Задача:** у документа должна появиться кнопка печати со своей формой.

**Механизм:** процедура `ДобавитьКомандыПечати(КомандыПечати)` в модуле менеджера
объекта. Библиотека собирает команды со всех объектов формы и строит подменю
печати.

**Ключевые свойства строки команды:**

- `Идентификатор` - имя макета либо свой идентификатор.
- `Представление` - что видит пользователь в меню.
- `Обработчик` - для нетипового поведения; иначе печать идет через менеджер
  печати объекта.
- `МенеджерПечати` - полное имя объекта, чья процедура `Печать` вызывается.

**Нюансы и антипаттерны:**

- Не добавлять кнопку печати на форму руками: собранная библиотекой команда
  попадает и в форму объекта, и в форму списка, и в подменю рассылки.
- Идентификатор команды должен совпадать с именем макета, если обработчик не
  задан: библиотека ищет макет по нему.

### 2. Сформировать печатную форму в коде

**Задача:** в процедуре `Печать` менеджера объекта заполнить табличный документ и
отдать его библиотеке.

**Функции:**

`УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(КоллекцияПечатныхФорм, ИмяМакета, СинонимМакета, ТабличныйДокумент, Картинка = Неопределено, ПолныйПутьКМакету = "", ИмяФайлаПечатнойФормы = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, ИмяМакета) Экспорт`
- функция, тот же регион: пользователь мог снять галку с этой формы.

**Пример:**

```bsl
// Модуль менеджера документа, процедура Печать.
Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм,
    ОбъектыПечати, ПараметрыВывода) Экспорт

    Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, "Накладная") Тогда
        УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(
            КоллекцияПечатныхФорм, "Накладная", "Накладная",
            СформироватьНакладную(МассивОбъектов, ОбъектыПечати));
    КонецЕсли;

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не формировать макет, не спросив `НужноПечататьМакет`: пользователь мог снять
  галку, и работа уйдет впустую, а на пакетной печати это заметно.
- Заполнять `ОбъектыПечати` обязательно: по нему библиотека связывает области
  документа с объектами и печатает их пачкой.
- Не возвращать табличный документ из процедуры: он кладется в коллекцию, а
  печатью управляет библиотека.

### 3. Выполнить команду печати с клиента

**Задача:** своя кнопка на форме должна печатать так же, как типовая.

**Функции:**

`УправлениеПечатьюКлиент.ВыполнитьКомандуПечати(ИмяМенеджераПечати, ИменаМакетов, МассивОбъектов, ВладелецФормы, ПараметрыПечати = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Тонкий и толстый клиент.

`УправлениеПечатьюКлиент.ВыполнитьКомандуПечатиНаПринтер(ИмяМенеджераПечати, ИменаМакетов, МассивОбъектов, ПараметрыПечати = Неопределено) Экспорт`
- процедура, тот же регион: минуя предварительный просмотр.

**Пример:**

```bsl
&НаКлиенте
Процедура НапечататьНакладную(Команда)

    Объекты = Новый Массив;
    Объекты.Добавить(Объект.Ссылка);

    УправлениеПечатьюКлиент.ВыполнитьКомандуПечати(
        "Документ.РасходТовара", "Накладная", Объекты, ЭтаФорма);

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не звать серверный `УправлениеПечатью` из клиентского обработчика: у него нет
  контекста тонкого клиента. Печать с клиента идет через модуль с суффиксом
  `Клиент`.
- Печать на принтер без просмотра не спрашивает пользователя ни о чем. Для
  массовой печати это нужно, для одиночной обычно нет.

### 4. Вмешаться в состав команд печати

**Задача:** скрыть типовую команду печати при определенных условиях либо
добавить свою в чужую форму.

**Функции:**

`УправлениеПечатьюПереопределяемый.ПередДобавлениемКомандПечати(ИмяФормы, КомандыПечати, СтандартнаяОбработка) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

`УправлениеПечатью.ДобавитьУсловиеВидимостиКоманды(КомандаПечати, Реквизит, Значение, Знач МетодСравнения = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`: условие видимости по реквизиту
объекта, вычисляется библиотекой.

**Нюансы и антипаттерны:**

- Не вызывать процедуры `УправлениеПечатьюПереопределяемый` из прикладного кода:
  их реализуют.
- Видимость по реквизиту задается через `ДобавитьУсловиеВидимостиКоманды`, а не
  своим кодом в форме: библиотека вычислит его один раз на список объектов, а
  свой код в форме - на каждое открытие.

### 5. Вмешаться в сам процесс печати

**Задача:** подставить свои параметры вывода или изменить набор форм перед
отправкой почтой.

**Функции:**

`УправлениеПечатьюПереопределяемый.ПередПечатью(Знач ИдентификаторПечатнойФормы, ОбъектыПечати, ПараметрыПечати) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

`УправлениеПечатьюПереопределяемый.ПередОтправкойПоПочте(ПараметрыОтправки, ПараметрыВывода, ОбъектыПечати, ПечатныеФормы) Экспорт`
- процедура, тот же регион и та же роль.

**Нюансы и антипаттерны:**

- Хуки вызываются на КАЖДУЮ печать. Тяжелая работа в них замедляет каждое
  открытие формы печати.
- Не подменять здесь содержимое макета: за макет отвечает менеджер печати
  объекта, а эти хуки за параметры процесса.
