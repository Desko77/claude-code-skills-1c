# Массовые операции с данными

Четыре механизма БСП, работающих с данными пачками: загрузка из файла в
справочники, групповое изменение реквизитов, выгрузка объектов в файлы, отчет о
структуре подчиненности документов.

## Модули

| Модуль | Механизм | Контексты |
|---|---|---|
| `ЗагрузкаДанныхИзФайла` | загрузка табличных данных в справочники с сопоставлением | сервер, толстый клиент, внешнее соединение |
| `ЗагрузкаДанныхИзФайлаКлиентСервер` | общие правила разбора загружаемых данных | сервер и клиент |
| `ГрупповоеИзменениеОбъектовКлиент` | клиентская часть группового изменения | тонкий и толстый клиент |
| `ГрупповоеИзменениеОбъектовПереопределяемый` | точка расширения группового изменения | сервер, толстый клиент, внешнее соединение |
| `ВыгрузкаОбъектовВФайлы` | выгрузка объектов в файлы для последующей загрузки | сервер, толстый клиент, внешнее соединение |
| `СтруктураПодчиненностиПереопределяемый` | точка расширения отчета о связях документов | сервер, толстый клиент, внешнее соединение |

**У группового изменения и структуры подчиненности в публичном интерфейсе нет
серверного модуля без суффикса.** У первого доступны клиентская часть и точка
расширения, у второй только точка расширения: сами механизмы работают обработкой
и отчетом, а не вызовами из прикладного кода.

## Сценарии

### 1. Описать, что можно загружать из файла

**Задача:** свой справочник должен принимать загрузку из таблицы.

**Функции:**

`ЗагрузкаДанныхИзФайла.ОписаниеЗагружаемыхДанныхДляСправочников(ЗагружаемыеДанные, ОписаниеТипаОбъектаСопоставления, ЗаголовокКолонкиОбъектаСопоставления) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`ЗагрузкаДанныхИзФайла.НастройкиЗагрузкиДанных() Экспорт` - функция-конструктор,
тот же регион.

**Нюансы и антипаттерны:**

- Не писать свой разбор таблицы: библиотека берет на себя сопоставление колонок,
  распознавание существующих элементов и разбор неоднозначностей.
- Колонка сопоставления это то, по чему строка файла узнается в базе. Без нее
  загрузка создаст дубли вместо обновления.

### 2. Разобрать неоднозначности загрузки

**Задача:** строка файла подошла к нескольким элементам справочника.

**Функции:**

`ЗагрузкаДанныхИзФайла.НовыйСписокНеоднозначностей() Экспорт` - функция, регион
`ПрограммныйИнтерфейс`. Сервер.

`ЗагрузкаДанныхИзФайла.ЗаписатьСвойстваОбъекта(СсылкаНаОбъект, СтрокаТаблицы) Экспорт`
- процедура, тот же регион.

**Нюансы и антипаттерны:**

- Неоднозначность это не ошибка файла: одинаковые наименования у разных элементов
  штатны. Решение принимает пользователь, и механизм для этого есть.
- Молчаливый выбор первого подходящего элемента дает загрузку не туда, и это
  всплывает много позже.

### 3. Выгрузить объекты в файлы

**Задача:** сохранить пачку объектов в файлы заданного формата.

**Функции:**

`ВыгрузкаОбъектовВФайлы.СохранитьПоФорматуВФайл(КомандыВыгрузки, СписокОбъектов, НастройкиСохранения) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер. Публичный интерфейс механизма
состоит из одного метода.

**Нюансы и антипаттерны:**

- Не путать с обменом данными: здесь файлы для человека либо для внешней системы,
  а не сообщение синхронизации.
- Выгрузка на большом списке долгая. Ее место - фоновое задание.

### 4. Вмешаться в отчет о структуре подчиненности

**Задача:** в дереве связанных документов показать свои объекты по-своему.

**Функции:**

`СтруктураПодчиненностиПереопределяемый.ПередВыводомСвязанногоОбъекта(Объект, СвойстваОбъекта, Отказ) Экспорт`
и `СтруктураПодчиненностиПереопределяемый.ПриПолученииПредставления(ТипДанных, Данные, Представление, СтандартнаяОбработка) Экспорт`
- процедуры, регион `ПрограммныйИнтерфейс`. ХУКИ.

**Нюансы и антипаттерны:**

- Не вызывать процедуры переопределяемого модуля из прикладного кода: их
  реализуют.
- Хуки вызываются на КАЖДЫЙ узел дерева. Запрос внутри них дает столько запросов,
  сколько связанных документов.

### 5. Дополнить групповое изменение

**Задача:** свой объект должен поддерживать групповую правку реквизитов.

**Функции:**

Процедуры модуля `ГрупповоеИзменениеОбъектовПереопределяемый` - регион
`ПрограммныйИнтерфейс`. ХУКИ.

`ГрупповоеИзменениеОбъектовКлиент` - клиентская часть, вызывается из формы.

**Нюансы и антипаттерны:**

- Групповое изменение записывает объекты по одному, со всеми проверками и
  подписками. Это не пакетная запись, и на больших списках она долгая.

## Различия версий

Состав модулей всех четырех механизмов в 3.1.11 и 3.2.1 совпадает - сверено по
обеим поставкам.
