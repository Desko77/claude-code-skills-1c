# Обмен данными

Механизм БСП, синхронизирующий данные между информационными базами: настройки
узлов и подключений, запуск и мониторинг обмена, регистрация изменений,
универсальный формат обмена.

Самая крупная тема библиотеки: 79 разделов документации и 291 метод в основном
модуле. Здесь только точки входа прикладного кода, а не устройство механизма
целиком.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `ОбменДаннымиСервер` | программный интерфейс сервера, 291 метод | сервер, толстый клиент, внешнее соединение |
| `ОбменДаннымиXDTOСервер` | универсальный формат обмена: отправка, получение, правила конвертации | сервер, толстый клиент, внешнее соединение |
| `ОбменДаннымиКлиент` | клиентская часть: помощники настройки и мониторинг | тонкий и толстый клиент |
| `Обработка.УниверсальныйОбменДаннымиXML` (модуль объекта) | обмен по правилам конвертации | сервер |

**Часть интерфейса объявлена НЕ в общих модулях.** Универсальный обмен и
конвертация объектов опубликованы модулями объектов обработок. Проверка вызова
для них работает иначе: в коде обращение идет к переменной с подключенным
объектом, и автоматически сверить его нельзя - сигнатура сверяется с модулем
объекта вручную.

## Сценарии

### 1. Запустить обмен из кода

**Задача:** синхронизация по расписанию или по действию пользователя.

**Функции:**

`ОбменДаннымиСервер.ВыполнитьДействиеОбмена(Отказ, УзелИнформационнойБазы, ДействиеПриОбмене, ИдентификаторТранспорта = Неопределено, ДополнительныеПараметры = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ОбменДаннымиСервер.ВыполнитьОбменДаннымиСВнешнейСистемой(Корреспондент, ПараметрыОбмена, ФлагОшибка) Экспорт`
- процедура, тот же регион.

**Нюансы и антипаттерны:**

- Не собирать сообщение обмена платформенными средствами мимо библиотеки: тогда
  не отработают регистрация изменений, протокол и разбор конфликтов.
- Параметр `Отказ` передается по ссылке. Проверять его после вызова обязательно:
  обмен завершается без исключения и при ошибке.
- Обмен долгий. Запуск из формы делается фоновым заданием, а не синхронно.

### 2. Прочитать настройку плана обмена

**Задача:** узнать, что поддерживает конкретный обмен, до его запуска.

**Функции:**

`ОбменДаннымиСервер.ЗначениеНастройкиПланаОбмена(ИмяПланаОбмена, ИмяПараметра, ИдентификаторНастройки = "", ВерсияКорреспондента = "") Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

**Нюансы и антипаттерны:**

- Настройки зависят от ВЕРСИИ корреспондента: одна и та же настройка у баз разных
  версий отличается. Параметр версии не декоративный.

### 3. Завершить настройку синхронизации

**Задача:** после создания узла обмена из кода довести настройку до рабочего
состояния.

**Функции:**

`ОбменДаннымиСервер.ЗавершитьНастройкуСинхронизацииДанных(УзелОбмена) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Сервер.

`ОбменДаннымиСервер.ЗавершитьСозданиеНачальногоОбраза(УзелОбмена) Экспорт`
- процедура, тот же регион.

**Нюансы и антипаттерны:**

- Создание узла записью объекта плана обмена НЕ завершает настройку: без этих
  вызовов обмен будет числиться настроенным и не работать.
- Начальный образ создается один раз. Повторный вызов на рабочем узле сбросит
  состояние регистрации изменений.

### 4. Управлять регистрацией изменений

**Задача:** перерегистрировать данные к отправке после исправления.

**Механизм:** регистрация изменений ведется планом обмена платформы, но библиотека
добавляет к ней свои правила и служебные данные. Прикладной код обращается к
методам `ОбменДаннымиСервер`, а не к платформенному плану обмена напрямую.

**Нюансы и антипаттерны:**

- Прямая запись в план обмена платформы обходит служебные регистры библиотеки:
  обмен отправит данные, но состояние синхронизации разъедется.
- Массовая перерегистрация тяжелая. Ее делают фоново и порциями.

## Различия версий

**Обработки `УниверсальныйОбменДаннымиXML` в дистрибутиве 3.2.1 уже нет** - это
записано и в справочнике `1c-bsp-api`. Код, обращающийся к ней, при переходе на
3.2.1 перестанет работать; обмен переводится на универсальный формат
`ОбменДаннымиXDTOСервер`.

## Проверка перед использованием

```bash
python skills/1c-bsp-api/scripts/bsp-api.py check ОбменДаннымиСервер.ВыполнитьДействиеОбмена
```

Для интерфейса, объявленного модулями объектов обработок, автоматическая проверка
недоступна: сигнатура сверяется с модулем объекта в поставке вручную.
