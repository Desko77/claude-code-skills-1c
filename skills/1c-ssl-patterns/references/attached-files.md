# Работа с файлами

Механизм БСП, присоединяющий файлы к объектам конфигурации: договор со сканом,
заказ с накладной, элемент справочника с фотографией. Хранение в базе либо в
томах на диске, версии файла, редактирование во внешней программе.

Не путать с выгрузкой объектов в файлы: там сериализация данных, здесь
пользовательские файлы, привязанные к объекту.

## Модули механизма

| Модуль | Роль | Контексты |
|---|---|---|
| `РаботаСФайлами` | программный интерфейс сервера | сервер, толстый клиент, внешнее соединение |
| `РаботаСФайламиКлиент` | программный интерфейс клиента: открытие, добавление, редактирование, сканирование | тонкий и толстый клиент |
| `РаботаСФайламиКлиентСервер` | общая часть: разбор имен, проверка расширений | сервер и клиент |
| `РаботаСФайламиПереопределяемый`, `РаботаСФайламиКлиентПереопределяемый` | точки расширения сервера и клиента | сервер / клиент |
| `РаботаСФайламиЛокализация` | национальная специфика | сервер |
| `РаботаСФайламиСлужебный` и еще восемь | внутренняя реализация библиотеки | - |

Клиентский модуль здесь БОЛЬШЕ серверного: 53 метода против 38. Работа с файлом -
действие пользователя, и почти все команды живут на клиенте.

## Сценарии

### 1. Прочитать файл, присоединенный к объекту

**Задача:** получить двоичные данные вложения, чтобы отправить его почтой или
разобрать.

**Функции:**

`РаботаСФайлами.ДвоичныеДанныеФайла(Знач ПрисоединенныйФайл, Знач ВызыватьИсключение = Истина) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`РаботаСФайлами.ДвоичныеДанныеФайлов(Знач ПрисоединенныеФайлы, Знач ВызыватьИсключение = Истина) Экспорт`
- функция, тот же регион: для нескольких файлов сразу.

`РаботаСФайлами.ДанныеФайла(Знач ПрисоединенныйФайл, Знач ДополнительныеПараметры = Неопределено, Знач УдалитьПолучатьСсылкуНаДвоичныеДанные = Истина, Знач УдалитьДляРедактирования = Ложь) Экспорт`
- функция, тот же регион: структура со сведениями о файле, а не сами данные.

**Пример:**

```bsl
&НаСервере
Функция СодержимоеВложения(Знач ФайлСсылка)

    Возврат РаботаСФайлами.ДвоичныеДанныеФайла(ФайлСсылка, Ложь);

КонецФункции
```

**Нюансы и антипаттерны:**

- Не читать реквизит хранилища значения справочника файлов напрямую: файл может
  лежать в томе на диске, а не в базе, и в хранилище его не будет.
- Для нескольких файлов брать `ДвоичныеДанныеФайлов`, а не звать одиночную
  функцию в цикле: она ходит в тома по одному разу на файл.
- Параметр `ВызыватьИсключение` со значением `Ложь` возвращает `Неопределено`
  вместо ошибки, когда файла нет. Для фоновой обработки это нужнее исключения.

### 2. Присоединить файл к объекту из кода

**Задача:** загрузка из внешней системы должна класть документы к заказу.

**Функции:**

`РаботаСФайлами.ДобавитьФайл(ПараметрыФайла, Знач АдресФайлаВоВременномХранилище, Знач АдресВременногоХранилищаТекста = "", Знач Описание = "", Знач НоваяСсылкаНаФайл = Неопределено) Экспорт`
- функция, регион `ПрограммныйИнтерфейс`. Сервер.

`РаботаСФайлами.ДобавитьФайлСДиска(ВладелецФайлов, ПутьКФайлуНаДиске) Экспорт`
- функция, тот же регион.

`РаботаСФайлами.НоваяСсылкаНаФайл(ВладелецФайлов, ИмяСправочника = Неопределено) Экспорт`
- функция, тот же регион.

**Нюансы и антипаттерны:**

- Не создавать элемент справочника присоединенных файлов записью объекта: мимо
  библиотеки не запишутся версия, размер, признак хранения в томе.
- Владелец должен допускать присоединение файлов - проверяется функцией
  `РаботаСФайлами.КОбъектуМожноПрисоединятьФайлы`. Иначе файл повиснет без хозяина.
- `ДобавитьФайлСДиска` читает путь НА СЕРВЕРЕ. Для файла с машины пользователя
  сначала помещают его во временное хранилище на клиенте.

### 3. Открыть файл у пользователя

**Задача:** по команде формы показать вложение во внешней программе.

**Функции:**

`РаботаСФайламиКлиент.ОткрытьФайл(Знач ДанныеФайла, Знач ДляРедактирования = Ложь) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Тонкий и толстый клиент.

`РаботаСФайламиКлиент.ДанныеФайла(Знач ФайлСсылка, Знач ИдентификаторФормы = Неопределено, Знач ПолучатьСсылкуНаДвоичныеДанные = Истина, Знач ДляРедактирования = Ложь) Экспорт`
- функция, тот же регион.

`РаботаСФайламиКлиент.ОткрытьКаталогФайла(ДанныеФайла) Экспорт` - процедура, тот
же регион.

**Пример:**

```bsl
&НаКлиенте
Процедура ОткрытьВложение(Команда)

    ДанныеФайла = РаботаСФайламиКлиент.ДанныеФайла(Элементы.Файлы.ТекущаяСтрока,
        УникальныйИдентификатор);
    РаботаСФайламиКлиент.ОткрытьФайл(ДанныеФайла);

КонецПроцедуры
```

**Нюансы и антипаттерны:**

- Не звать серверный `РаботаСФайлами.ДанныеФайла` из клиентского обработчика: у
  него контексты сервера, толстого клиента и внешнего соединения. Для клиента
  есть одноименная функция в модуле с суффиксом `Клиент`, и сигнатуры у них
  РАЗНЫЕ.
- Идентификатор формы передается, чтобы данные во временном хранилище жили,
  пока открыта форма. Без него ссылка протухнет.

### 4. Добавить файл действием пользователя

**Задача:** кнопка на форме, открывающая диалог выбора файла.

**Функции:**

`РаботаСФайламиКлиент.ДобавитьФайл(ОбработчикРезультата, ВладелецФайла, ФормаВладелец, РежимСоздания = Неопределено, ПараметрыДобавления = Неопределено) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. Клиент.

`РаботаСФайламиКлиент.ДобавитьФайлы(Знач ВладелецФайла, Знач ИдентификаторФормы, Знач Фильтр = "", ГруппаФайлов = Неопределено, ОбработчикРезультата = Неопределено) Экспорт`
- процедура, тот же регион: несколько файлов сразу.

`РаботаСФайламиКлиент.ДобавитьСоСканера(ПараметрыДобавления, ПараметрыСканирования = Неопределено) Экспорт`
- процедура, тот же регион.

**Нюансы и антипаттерны:**

- Работа асинхронная: результат приходит в обработчик оповещения, а не
  возвращается из процедуры. Код после вызова выполняется ДО того, как
  пользователь выбрал файл.
- Не собирать диалог выбора файла самостоятельно: библиотека проверяет
  расширение, размер и настройки хранения, а свой диалог этого не делает.

### 5. Ограничить, какие файлы принимаются

**Задача:** запретить вложения сверх размера или с опасным расширением.

**Функции:**

`РаботаСФайлами.МаксимальныйРазмерФайла() Экспорт` и
`РаботаСФайлами.МаксимальныйРазмерФайлаОбщий() Экспорт` - функции, регион
`ПрограммныйИнтерфейс`. Сервер.

`РаботаСФайлами.НастройкиРаботыСФайлами() Экспорт` - функция, тот же регион.

`РаботаСФайламиПереопределяемый.ПриОпределенииНастроек(Настройки) Экспорт`
- процедура, регион `ПрограммныйИнтерфейс`. ХУК.

**Нюансы и антипаттерны:**

- Не проверять размер и расширение своим кодом до вызова библиотеки: настройки
  меняются администратором, и своя проверка разойдется с настройкой.
- Не вызывать процедуры `РаботаСФайламиПереопределяемый` из прикладного кода: их
  реализуют.

## Различия версий

В 3.2.1 появился служебный модуль `РаботаСФайламиВХранилищеДвоичныхДанныхСлужебный`,
которого нет в 3.1.11 - сверено по обеим поставкам. Модуль служебный, на
прикладной код это не влияет, но объясняет разницу в составе семейства.

Состав публичных модулей и их экспортных методов в этих версиях совпадает.
