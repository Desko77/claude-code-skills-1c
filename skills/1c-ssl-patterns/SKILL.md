# 1C SSL/БСП Subsystems Reference

MCP-сервер: **1c-mcp_ssl_server**. Справочник по Библиотеке стандартных подсистем (БСП/SSL).

## When to Use

- Работа с пользователями и правами доступа
- Работа с файлами и вложениями
- Печатные формы
- Фоновые задания с прогрессом
- Версионирование объектов
- Отправка email
- Общие утилиты (массивы, структуры, строки)

## Core Principle

**ВСЕГДА проверяй, есть ли решение в БСП, прежде чем писать свой код.**

## MCP Tools

### `ssl_search` - поиск функций БСП

У сервера `1c-mcp_ssl_server` РОВНО ОДИН инструмент. Векторный (семантический) поиск по документации БСП, не полнотекстовый: запрос формулируется как описание задачи на русском. Возвращает найденные описания, разделенные `---`.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `query` | да | Описание задачи или имя метода на русском |

Примеры:
- `ssl_search("фоновое задание прогресс")` - найти API длительных операций
- `ssl_search("копирование структуры")` - утилиты работы со структурами
- `ssl_search("значение реквизита объекта")` - получение реквизитов
- `ssl_search("отправка почтового сообщения")` - API отправки email
- `ssl_search("печатная форма макет")` - API управления печатью

Инструментов вида `get_function_info` / `search_modules` / `get_subsystem_info` на сервере НЕТ - не вызывать. Детали найденного метода брать из шага 2 workflow.

## SSL Search Workflow

1. **Поиск в БСП** - `ssl_search` с описанием задачи
2. **Детали метода** - уточняющий `ssl_search` по имени метода; сигнатуру и шапку смотреть в реальной выгрузке БСП проекта (`read_method_source` 1c-edt либо Grep по `src/CommonModules/...`)
3. **Поиск в проекте** - `search_in_code` (1c-edt) - как используется в кодовой базе
4. **Только потом свой код** - если БСП не подходит

Существование модуля или метода БСП подтверждать ТОЛЬКО реальной выгрузкой конфигурации (ls/Grep/`read_method_source`). Ни `ssl_search`, ни `its_help` не являются доказательством: они судят по документации и могут назвать метод, которого нет в этой версии БСП.

## Key SSL Modules

| Модуль | Назначение |
|--------|-----------|
| **ОбщегоНазначения** | ЗначениеРеквизитаОбъекта, ЗначенияРеквизитовОбъектов, КопироватьРекурсивно, СообщитьПользователю |
| **ОбщегоНазначенияКлиентСервер** | Проверки, работа со структурами, массивами |
| **СтроковыеФункцииКлиентСервер** | Форматирование, разбор, подстановка параметров в строки |
| **Пользователи** | Текущий пользователь, роли, права доступа |
| **РаботаСФайлами** | Хранение, получение, присоединенные файлы |
| **УправлениеПечатью** | Регистрация, генерация, управление печатными формами |
| **ДлительныеОперации** | ВыполнитьВФоне, ОжидатьЗавершение, передача прогресса |
| **ВерсионированиеОбъектов** | История изменений объектов |
| **РаботаСПочтовымиСообщениями** | Отправка email через учетные записи |
