# Особенности СКД и отчетов 1С

Применяется: при доработке отчетов на СКД - схема `.dcs`, модуль отчета, программная компоновка,
вывод в табличный документ.

Двухпроходная компоновка, набор-объект в файле схемы, параметры-выражения и
`МакетКомпоновки.ЗначенияПараметров` - `1c-skd-two-pass-preprocessing.md`. Выполнение запроса отчета
без компоновки - `1c-report-direct-query.md`.

---

## Отборы и поля в тексте запроса

- **`{ГДЕ}` и программные отборы СКД подставляются во ВСЕ временные таблицы пакета с тем же
  псевдонимом**, а не только в итоговый запрос. Поля, вычисленные на уровне документа, теряют ветки
  `ОБЪЕДИНИТЬ`. Защита: расчетным полям во временных таблицах давать префикс (`Расч_`), в итоговом
  запросе ссылаться на них, `{ГДЕ}` писать по исходным псевдонимам итогового запроса.
- **`{ВЫБРАТЬ}` ищет поля по реальным именам таблиц, а не по псевдонимам `КАК`** - оборачивать поле
  в `ВЫБОР КОГДА ... КОНЕЦ КАК X`.
- **Отборы СКД (`{ГДЕ}`) не подставляются в параметры виртуальных таблиц** (`.Остатки`, `.Обороты`) -
  фильтр внутри виртуальной таблицы задается только через `&Параметр` (`УстановитьПараметр`).
- **Оптимизатор СКД удаляет поля, вычисленные `ВЫРАЗИТЬ` во временной таблице**, если их нет в
  выводе: под ограниченной ролью колонка пропадает. Перевести поле на разыменование
  (`Регистратор.Номер`) в выражении поля СКД - оно вычисляется при выводе, а не в SQL, поэтому
  точка здесь допустима, в отличие от SQL под RLS.

## Схема .dcs

- **Типы полей набора-объекта (`DataSetObject`) в `.dcs`:** Number - `xs:decimal` с `Digits` /
  `FractionDigits` (не `Precision` / `Scale`, это формат `.mdo`); String - `StringQualifiers` /
  `Length`; Date - `xs:dateTime` с `DateFractions`; ссылка - через пространство имен
  `current-config` (`d4p1:CatalogRef.X`).
- **`userSettingID` допустим только в отдельном `userSettings` на уровне `settingsVariant`**, а не
  внутри `SettingsParameterValue`.
- **В закомментированных строках запроса в `.dcs` - только `&lt;&gt;`**, а не `<>`.
- **Схема без `<dataSet>` (только параметры и `settingsVariant`) - допустимая схема**: данные
  передаются через `ВнешниеНаборыДанных` в коде. Набор данных в нее не добавлять.

## Условное оформление

- **`conditionalAppearance` по полю-счетчику окрашивает и итоги, группировки, заголовки** - задавать
  полный блок `useIn*=DontUse`.
- Ресурсное поле (`totalField` с `Массив` / `Различные`) с пустым `selection` не окрашивается -
  отдельный элемент оформления с явным полем.

## Вывод и форма отчета

- **Скрытие пустых строк и столбцов табличного документа**:
  `Область("R" + Формат(N, "ЧГ=0")).Видимость = Ложь`. `Строка(N)` при N >= 1000 дает разделитель
  групп ("1 039"), прямоугольная область строку не скрывает. Ресурсные колонки определяются по
  `.Формат` (начинается с "Ч"), граница шапки - `ФиксацияСверху`. Способ скрывает и заголовки
  группировок; без следов в результате - двухпроходная компоновка.
- **`Новый ОписаниеТипов(Колонка.ТипЗначения.Типы())` теряет квалификаторы** (длина, точность) -
  колонки пропадают после `Вывести`. Копию типа реквизита давать через `РеквизитФормыВЗначение`.
- **Отчет в новой вкладке при каждом открытии**: своя команда `Reports.X.Commands.Y` и
  `Новый УникальныйИдентификатор` четвертым параметром `ОткрытьФорму`. Перехват
  `ВариантыОтчетовКлиент` БСП не подходит: открытие из подсистемы идет автокомандой, минуя БСП.
  Перед выбором точки перехвата проверять, каким вызовом открывается отчет.
- **Сворачиваемая панель отборов во внешнем отчете (EPF/ERF)** не требует флага
  `ТеснаяИнтеграция`: БСП вызывает `ОпределитьНастройкиФормы` и без него. Зарегистрировать
  `ПриСозданииНаСервере` и изменить группу пользовательских настроек.
