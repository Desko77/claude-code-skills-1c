# Особенности 1С 7.7: коллекции, правка модулей, обмен

Применяется: при правке модулей 1С 7.7 и при переносе данных из 7.7 в 8.x.

Синтаксис 7.7 (логический тип в `Если`, `ПустаяСтрока`, `Симв()`, скобки в составных условиях),
кодировка CP1251 и сборка `.ert` - скил `1c77-dev`.

---

## Коллекции

- **`СписокЗначений.НайтиЗначение` ищет только по значению** (один параметр).
- **У `ТаблицаЗначений` есть `ВыбратьСтроки()` / `ПолучитьСтроку()`**: обход
  `Пока ПолучитьСтроку() = 1 Цикл`. `"Ссылка"` - допустимое имя колонки таблицы значений.
- Замечания 1С:Напарника к коду 7.7 часто применяют семантику 8.x - проверять по факту разбором
  `gcomp`, а не принимать.

## Правка модулей скриптом

- **Правка `.1s` из Python: литералы с `\n` и `\t` - в raw-строках `r'...'`**, иначе в модуль попадает
  настоящий перевод строки, строка BSL разрывается, и компиляция отказывает "Ожидается КонецЕсли".
  Файл открывать с `encoding='cp1251'` (поиск по кириллице в UTF-8 его не находит).

## Обмен и миграция

- **Выгрузка JSON из 7.7 пишет TAB, LF и CR в значениях без экранирования** - очищать перед
  `ПрочитатьJSON` в 8.x.
- **HTTP из 7.7 - COM-объект `WinHttp.WinHttpRequest.5.1`**; TLS 1.2 включается `Option(9) = 2048`.
- **Миграция 7.7 -> УНФ**: НСИ - разовой обработкой (`.ert` -> `.epf`), документы - двусторонним
  обменом EnterpriseData (XML строго по XDTO УНФ, порядок полей значим), типовых правил поставщика нет.
  Остатки - в `InformationRegister` с `writeMode=Independent`.
