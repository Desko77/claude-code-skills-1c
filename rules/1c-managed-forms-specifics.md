# Особенности управляемых форм 1С

Применяется: при доработке управляемых форм - `Form.form` EDT-проекта, модуль формы, доработка
типовой формы в расширении.

Требования к XML `Form.form` - `edt-form-xml-requirements.md`, маршрут правки форм -
`forms_generation.md`, зарезервированные имена - `1c-form-reserved-names.md`.

---

## Доработка типовой формы в расширении

- **Типовую форму в расширении дорабатывать программно, обработчиками BSL**, а не заимствованием с
  правкой XML формы: EDT не разрешает `dataPath=Объект.<РеквизитРасширения>` (блок `<attributes>`
  заимствованной формы не наследует расширенный тип). Заимствовать только `Module.bsl` (или
  `form=Extended` с пустой адаптацией интерфейса, где `Form.form` совпадает с `BaseForm`), элементы
  создавать во время выполнения с проверкой `Элементы.Найти() <> Неопределено` и ранним выходом.
  Свойства `Module=Extended` у форм нет, есть только `form=Extended`. `Form.form` вручную не править.
- **Имя процедуры-перехватчика события формы - с префиксом и не совпадает с перехватываемой**
  (`Расш_ПриСозданииНаСервере`). Перехват событий формы - `<handlers xsi:type="form:EventHandlerExtension">`
  с `callType=Before` / `After` в `Form.form`. Типовой обработчик, назначенный через
  `УстановитьДействие()`, не заменять, а перехватывать `&После`, иначе теряются серверные вызовы и
  пересчет. `&НаСервереБезКонтекста` форму не принимает.
- **Дизайнер EDT при пересохранении формы удаляет аннотации `&После` / `&Перед` /
  `&ИзменениеИКонтроль`**, переименовывает процедуру (добавляет суффикс) и создает лишний
  `<handlers>`: двойной вызов дает "Неуникальное имя реквизита". После операций в дизайнере проверять
  аннотации и сравнивать `Form.form` с `BaseForm/Form.form`.
- При пересоздании таблицы `DynamicList` EDT добавляет лишние `<notDefaultUseAlwaysAttributes>` и
  `<handlers>` без `<event>` - Конфигуратор отказывает "Неверный путь к данным". Удалять их после
  пересоздания.

## Динамический список

- **`Form.form` формы списка справочника требует `extInfo DynamicListFormExtInfo` и
  `autoFillAvailableFields`**, иначе деплой отказывает "Неверный путь Список.Code/Ref".
- **`ДанныеСтроки` динамического списка содержит только ключевые поля и поля с "Использовать
  всегда"** (флаг ставится только в дизайнере). Реквизит, выведенный колонкой, недоступен: брать ключ
  (`НомерЗаписи`) и читать запросом на сервере.
- **Динамический список с произвольным запросом**: фильтр через
  `УстановитьЭлементОтбораДинамическогоСписка` или настройки, а не `&Параметр` в `queryText` (8.3.27 не
  разрешает).
- **`Список.DefaultPicture` и `rowPictureDataPath` на динамическом списке с основной таблицей
  регистра** - деплой на 8.3.27 отказывает "Неверный путь Список.DefaultPicture". Допустимы только для
  справочников, документов, задач и бизнес-процессов. Методов `StdPicture.Save` /
  `LoadDataReport` в 8.3.27 нет.

## Элементы формы

- **`footerDataPath` (итог в подвале) - только для числовых колонок**; на дате, строке или ссылке
  загрузка в Конфигуратор отказывает "Тип колонки не суммируемый" (EDT это не проверяет).
  `<showInFooter>` можно оставить.
- **Текст подвала поля - `ТекстПодвала`**, а не `Подвал` (это булево свойство таблицы).
- **Обработчики событий полей в `Form.form`:** `OnChange` - на уровне `<items>/<handlers>`,
  `StartChoice` - внутри `<extInfo InputFieldExtInfo>` (на уровне `items` не вызывается).
- **Поле `CheckBoxField` только для реквизита `Boolean`** - `edt-known-errors.md`.
- **Кроме имен из `1c-form-reserved-names.md`, не использовать как имена переменных и процедур формы**
  `Закрыть`, `Выполнить`, `ОписаниеОшибки`, `Тип`, `Значение`, `Знач`, `Строка` - брать конкретные
  имена (`ПараметрыВыбораСтатьи`).

## Данные формы

- **Скрытый реквизит формы с `useAlways=false` как серверный кеш**: клиенту не передается, доступен
  напрямую как `ЭтотОбъект.Имя` без `РеквизитФормыВЗначение`. Подходит для крупной `ТаблицаЗначений`
  между серверными вызовами. Для отложенной загрузки дерева `ВременноеХранилище` не подходит:
  упаковка дерева теряет его.
- **`ПользовательскиеНастройки.Элементы.Очистить()` запрещен** (связан с СКД) - очищать содержимое
  каждого элемента.
- **`ПодписиДокументов.ЗаполнитьПодписиПоОрганизации` в `ПриСозданииНаСервере` сбрасывает
  подписанта при каждом открытии** - вызывать под `Если Параметры.Ключ.Пустая()`.
- **Ввод одного значения - асинхронно** (`Ждать ВвестиДатуАсинх()`, `ВвестиСтрокуАсинх()`,
  `ВвестиЧислоАсинх()`, `ВопросАсинх()`) с проверкой на `Неопределено`, а не отдельной формой
  (`async-methods-1c.md`). Чат и сложный интерфейс - через `ПолеHTMLДокумента`, а не динамические
  реквизиты.
