# Анти-паттерны и рекомендации по производительности 1С

Таблица триггеров каталога дефектов генерируется из карточек скила `1c-code-review`
скриптом `tools/gen_catalog_index.py` и обновляется только через карточки. Подробности
каждого анти-паттерна - триггер, законная форма, важность, способ чинить - в карточке
каталога с тем же идентификатором. Прежняя нумерация пунктов этого файла сохранена
колонкой Псевдоним: ссылки вида п.N читаются по ней.

## Каталог дефектов

Секция генерируется `tools/gen_catalog_index.py` по карточкам каталога скила
`1c-code-review`; между маркерами не правится. Колонка Псевдоним сохраняет прежнюю
нумерацию пунктов этого файла: ссылки вида п.N читаются по ней. Подробности - в
карточке каталога с тем же идентификатором.
