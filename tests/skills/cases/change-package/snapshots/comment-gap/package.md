# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 1, добавлено: 0, удалено: 0, правок вне методов: 0

## CommonModules/Настройки/Ext/Module.bsl - Общий модуль Настройки

### Изменить метод СброситьКэш

Найти:

```bsl
// Сбрасывает накопленный кэш значений.
Процедура СброситьКэш()
	КэшЗначений = Новый Соответствие;
КонецПроцедуры
```

Заменить целиком на:

```bsl
// Сбрасывает накопленный кэш значений.

Процедура СброситьКэш()
	КэшЗначений = Новый Соответствие;
	СчетчикСбросов = СчетчикСбросов + 1;
КонецПроцедуры
```
