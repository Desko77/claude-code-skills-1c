# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 0, добавлено: 0, удалено: 0, правок вне методов: 1

## CommonModules/Настройки/Ext/Module.bsl - Общий модуль Настройки

### Изменить код вне методов в начале модуля

Найти:

```bsl
Перем КэшЗначений;
```

Заменить целиком на:

```bsl
Перем КэшЗначений, СчетчикВызовов;
```
