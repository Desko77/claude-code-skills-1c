# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 1, добавлено: 0, удалено: 0, правок вне методов: 0

## CommonModules/Обмен/Ext/Module.bsl - Общий модуль Обмен

### Изменить метод Подготовить

Найти:

```bsl
#Если Сервер Тогда
Процедура Подготовить()
	Результат = 1;
КонецПроцедуры
#Иначе
Процедура Подготовить()
	Результат = 2;
КонецПроцедуры
#КонецЕсли
```

Заменить целиком на:

```bsl
#Если Сервер Тогда
Процедура Подготовить()
	Результат = 1;
КонецПроцедуры
#Иначе
Процедура Подготовить()
	Результат = 3;
КонецПроцедуры
#КонецЕсли
```
