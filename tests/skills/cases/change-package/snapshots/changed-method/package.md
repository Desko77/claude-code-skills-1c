# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 1, добавлено: 0, удалено: 0, правок вне методов: 0

## Catalogs/Товары/Ext/ObjectModule.bsl - Справочник Товары, модуль объекта

### Изменить метод ЗаполнитьПоУмолчанию

Найти:

```bsl
&НаСервере
Процедура ЗаполнитьПоУмолчанию()

	Строка = "старое";
	УстановитьЗначение(Строка);

КонецПроцедуры
```

Заменить целиком на:

```bsl
&НаСервере
Процедура ЗаполнитьПоУмолчанию()

	Строка = "новое";
	УстановитьЗначение(Строка);
	Сообщить(Строка);

КонецПроцедуры
```
