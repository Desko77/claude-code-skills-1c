# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 1, добавлено: 0, удалено: 0, правок вне методов: 0

## CommonModules/Обмен/Ext/Module.bsl - Общий модуль Обмен

### Изменить метод ЗагрузитьФайлы

Найти:

```bsl
Асинх Процедура ЗагрузитьФайлы()
	Файлы = Ждать НайтиФайлыАсинх(Путь);
КонецПроцедуры
```

Заменить целиком на:

```bsl
Асинх Процедура ЗагрузитьФайлы()
	Файлы = Ждать НайтиФайлыАсинх(Путь, "*.txt");
	ПоместитьФайлы(Файлы);
КонецПроцедуры
```
