# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 0, добавлено: 0, удалено: 0, правок вне методов: 2

## CommonModules/Обмен/Ext/Module.bsl - Общий модуль Обмен

### Изменить код вне методов после метода СброситьКэш

Найти:

```bsl

МаксимумЗаписей = 100;
```

Заменить целиком на:

```bsl

МаксимумЗаписей = 200;
```

### Изменить код вне методов в конце модуля

Найти:

```bsl

ПорцияЗагрузки = 500;
```

Заменить целиком на:

```bsl

ПорцияЗагрузки = 1000;
```
