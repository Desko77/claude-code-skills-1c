# Пакет ручного внесения изменений

До: before
После: after

Модулей с правками: 1, методов изменено: 0, добавлено: 0, удалено: 0, правок вне методов: 0, замен целиком: 1

## CommonModules/Настройки/Ext/Module.bsl - Общий модуль Настройки

### Заменить модуль целиком

Найти:

```bsl
Процедура СброситьКэш()
	КэшЗначений = Новый Соответствие;
КонецПроцедуры
```

Заменить целиком на:

```bsl
Перем КэшЗначений;

Процедура СброситьКэш()
	КэшЗначений = Новый Соответствие;
КонецПроцедуры
```
