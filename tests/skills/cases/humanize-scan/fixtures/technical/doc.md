# Обновление индекса

Процедура досыпает элементы в конец коллекции и кладет результат в кеш. Разбор идет под капотом,
поэтому из коробки работает и на клиенте. Модуль умеет читать реквизиты.

```
// В блоке кода оборот не считается: досыпает, под капотом
Процедура Тест() Экспорт
КонецПроцедуры
```
