=== Тип XDTO: Документ ===  (глубина 4)
Пакет: nested · urn:test:nested

Свойства (3):
  Реквизиты         объект Реквизиты    [обязательный]
    Наименование    Строка              [обязательный]
  Дочерний          объект Документ     [список]
    (раскрыт выше)
  Встроенный        объект (анонимный)  [обязательный]
    Ид              Строка              [обязательный]
    __content       Дата                [обязательный, значение элемента]

Обозначения:
  объект X — присвоить вложенный объект XDTO, состав раскрывает -Depth
  список — коллекция, заполняется через .Добавить()
  значение элемента — собственное значение узла XML

Создание:
  Тип = ФабрикаXDTO.Тип("urn:test:nested", "Документ");
  Объект = ФабрикаXDTO.Создать(Тип);
  // вложенный именованный тип — так же, как корневой:
  Реквизиты = ФабрикаXDTO.Создать(ФабрикаXDTO.Тип("urn:test:nested", "Реквизиты"));
  // у анонимного типа нет имени — только через свойство владельца:
  Встроенный = ФабрикаXDTO.Создать(Тип.Свойства.Получить("Встроенный").Тип);
  // собственное значение узла лежит в свойстве __content
