Сними гейт качества или отдельную проверку с записью в след проверок.

Событие `release` пишет хук `hooks/release-writer.mjs` по набранному промпту: команда
ничего не выполняет сама и работает только при включенных хуках набора (включение -
`hooks/README.md`). Если хуки набора не включены, скажи об этом пользователю и ничего
не записывай.

## Синтаксис

```
/quality release gate <причина> [--for 30m|2h|1d]
/quality release check <проверка@среда> <причина> [--for 30m|2h|1d]
```

- Область `gate` снимает гейт завершения хода целиком, область `check` - одну проверку.
- Срок по умолчанию - 4 часа; формы срока: `30m`, `2h`, `1d`.
- Формат события `release` - `skills/1c-code-review/references/evidence-format.md`.
